# Spec: CC Player MVP

## Problem Statement

用户在安卓上看本地与 NAS（SMB/WebDAV）里的视频和音频，现有播放器要么格式/字幕支持不全（尤其 mkv 内 ASS 字幕渲染差），要么不能自由切换解码方式、不能方便地连播/循环/在播放器内切换剧集，也不记住播放位置。

播放界面布局不符合预期：控制项分散、按钮位置不固定、选项需要反复点击切换；手势区域过大，缺少进度拖动与双击暂停，容易误触。打开 SMB 大文件时长时间黑屏且没有任何反馈；切集时会闪黑或露出新画面；从后台回到前台会黑屏；自动下一集卡在“正在缓冲”；上一集按钮点了没反应；播放列表点击会恒定偏移一项。通知栏没有标题、封面，时长与进度也不对。

浏览与入口缺少统一规则：不同页面的入口与返回方式不一致，排序与视图离浏览现场太远，调整要来回跳；添加 WebDAV 源时明文 HTTP 地址连不上；网络视频封面出得慢且常是黑帧；设置页开关行与选项行宽度不一致，弹出选项靠左；浏览条目点击没有反馈，点开后还要等目录重扫才进播放页。

## Solution

CC Player（`com.cc3301.ccplayer`）：以 libmpv（FFmpeg + libass）为播放核心的安卓播放器。

首页只有本地、SMB、WebDAV 三个协议入口，左上角汉堡按钮打开设置，标题居中显示 CC Player。源列表与库页面同样用汉堡按钮，离开靠系统返回；库页面顶栏右侧提供视图与排序。设置页左侧保留返回，回到进入前的界面。系统返回逐级回退，首页首次返回提示“再按一次退出”。

播放页顶栏与底栏透明，只在上下边缘保留极淡渐变；标题、转屏、更多、字幕、播放列表与锁定按钮按固定位置排列。控制层 5 秒无操作隐藏，显示与隐藏为淡入淡出。播放列表从右侧滑出、占半屏，当前项居中。解码、循环、方向、自动连播与定时都在“更多”的列表中选择。左右两侧竖条上下拖动调系统媒体音量，中间区域左右拖动跳转、双击暂停，左右侧双击分别后退/前进 10 秒，并在同侧显示箭头与累计秒数。

首次打开媒体时显示黑屏与缓冲提示；切集时保留冻结画面，缓冲指示以透明叠层盖在其上，新视频帧真正上屏后替换。两者都在 1000ms 后才显示缓冲提示。手动切集完成后自动播放。文件播完立即进入下一集。切集缓冲期间只允许返回与上一集/下一集；连点目标实时前移；失败取消切换并保持暂停。

列表与源列表只显示名称，不再写“文件夹 / 视频”说明；本地视频多帧抽样并跳过黑帧，网络视频取单帧。网络目录进入后可见项平均 1 秒内出封面。首页入口与源列表条目使用同一套卡片规格；设置页行高与右侧控件对齐，弹出选项靠右；只有浏览页条目点击显示白色涟漪。

通知栏显示文件名、封面、总时长与实时进度，并支持拖动定位。设置页提供诊断日志开关与导出；导出包含应用版本、设备型号与系统版本。

WebDAV 支持 `http://` 明文地址，目录请求补末尾斜杠。后台播放提供开关；关闭时退到后台立即暂停。

图标为白底蓝色播放三角；自适应图标中三角缩小 20% 并按视觉重心居中。

## User Stories

1. 作为用户，我想播放本地视频（mp4、mkv、webm、avi、mov、flv、ts、wmv），以便无需转码直接观看。
2. 作为用户，我想播放本地音频（mp3、opus、wav、flac、m4a、aac、ogg），以便统一管理音乐与有声内容。
3. 作为用户，我想播放 mkv 内嵌的 ASS 字幕并完整渲染样式，以便字幕与桌面播放器观感一致。
4. 作为用户，我想播放 mkv 内嵌的 SRT 字幕，以便纯文本字幕正常显示。
5. 作为用户，我想外挂字幕自动加载、内嵌字幕优先显示（没有内嵌时才默认用外挂），以便开箱就有字幕、又能优先用片源自带的。
6. 作为用户，我开启外挂字幕时内嵌字幕停止显示（任一时刻只有一路字幕生效），以便不叠字。
7. 作为用户，我想在播放器菜单里看到内嵌轨道、可匹配的外挂字幕与关闭三项，以便随时切换。
8. 作为用户，我想默认硬件解码、解码失败自动回退软件解码，以便流畅且兜底可靠。
9. 作为用户，我想在设置里全局选择硬件解码或软件解码，并在播放页“更多”列表里对当前会话切换，以便个别格式硬解异常（绿屏/花屏）时立即自救。
10. 作为用户，我想打开应用先看到首页，只有本地、SMB、WebDAV 三个来源入口，以便快速决定从哪里开始。
11. 作为用户，我想点击某个协议入口后看到该协议的连接源列表，以便集中管理同类来源。
12. 作为用户，我想源列表只显示连接源名称，以便快速识别已有连接。
13. 作为用户，我想源列表右下角有加号按钮，以便随时新增连接。
14. 作为用户，我想在没有连接源时看到空状态提示，但加号仍可用，以便知道下一步该做什么。
15. 作为用户，我想新增 SMB 连接时填写名称、服务器地址、路径、用户名与密码，以便连接局域网共享。
16. 作为用户，我想 SMB 服务器地址不填端口时默认 445，以便少填一项。
17. 作为用户，我想 SMB 路径可以只填共享名，也可以填共享名加子目录，以便直接进入常用目录。
18. 作为用户，我想 SMB 路径留空时列出服务器上的共享，以便不知道共享名时也能浏览。
19. 作为用户，我想新增 WebDAV 连接时填写名称、服务器地址、起始目录、用户名与密码，以便连接网盘或 NAS。
20. 作为用户，我想 WebDAV 地址不写端口时，http 默认 80、https 默认 443，以便少填一项。
21. 作为用户，我想 WebDAV 起始目录可空，为空时从服务器地址根目录开始，以便按需缩小浏览范围。
22. 作为用户，我想连接源名称可空，留空时 SMB/WebDAV 使用服务器地址、本地使用文件夹名，以便不想命名时也能保存。
23. 作为用户，我想编辑已保存的 SMB/WebDAV 连接，以便修改地址、路径或凭据。
24. 作为用户，我想删除连接前二次确认，且只删除本地记录与凭据、不删远程文件，以便避免误操作。
25. 作为用户，我想本地来源通过系统文件夹选择器添加，并且可以添加多个文件夹，以便管理不同磁盘位置。
26. 作为用户，我想本地连接源只提供删除，不提供编辑，以便操作符合它没有凭据的事实。
27. 作为用户，我想保存连接后它立即出现在源列表，以便确认保存成功。
28. 作为用户，我想点击连接源进入库页面，以便浏览该来源的根目录。
29. 作为用户，我想在库页面顶栏切换列表视图与 2/3/4 列网格，当前视图带勾选，以便按内容密度选择展示方式。
30. 作为用户，我想按名称排序且规则与 Windows 资源管理器一致（数字按数值、不分大小写，如 `2` 在 `10` 前），以便剧集顺序与电脑上相同。
31. 作为用户，我想排序选项为名称升序、名称降序、修改时间 新→旧、修改时间 旧→新，当前项带勾选，以便按不同需求整理目录。
32. 作为用户，我想子目录恒排在文件之前，以便目录结构稳定可预期。
33. 作为用户，我想网格卡片显示缩略图、文件名与时长角标，以便一眼识别。
34. 作为用户，我想音频卡片显示文件内嵌封面（无封面用音符占位图），本地与网络音频都一样，以便音乐库更直观。
35. 作为用户，我想屏幕方向设置四选一：屏幕方向（默认，随系统）/ 横屏 / 竖屏 / 跟随视频，以便适配不同内容。
36. 作为用户，我想“跟随视频”按宽高比判定方向（≥1 横、<1 竖），且播放中随比例变化旋转，以便混比例内容正确显示。
37. 作为用户，我想在画面中间左右拖动跳转进度，拖动中显示目标时间与增减量，松手才生效，以便精确定位不误触。
38. 作为用户，我想在左右两侧竖条内上下拖动调系统媒体音量，以便单手调节且不影响中间操作。
39. 作为用户，我想中间双击暂停/继续，左侧竖条双击后退 10 秒、右侧竖条双击前进 10 秒，以便快速微调。
40. 作为用户，我想锁定后只保留左上角解锁按钮，自动隐藏、点一次即解锁，以便口袋误触不打断播放又不遮挡画面。
41. 作为用户，我想当前文件播完自动播下一个（顺序播放到末尾停止），以便追剧不用点屏幕。
42. 作为用户，我想设置“自动播放下一个”开关，关闭时顺序/列表循环播完即停，以便挂机时不想让它继续。
43. 作为用户，我想单集循环，以便重复学习/听歌。
44. 作为用户，我想列表循环（末尾回第一个，配合自动连播），以便歌单/剧集无限续。
45. 作为用户，我想“上一集/下一集”始终按名称自然排序的相邻文件（与当前视图排序无关），以便连播顺序稳定可预期。
46. 作为用户，我想当前目录即播放列表，以便零配置连播。
47. 作为用户，我想在播放器内打开播放列表并点击切换，且点哪一集就播哪一集，以便不退出播放页选片。
48. 作为用户，我想定时暂停（10 分钟 / 30 分钟 / 1 小时 / 2 小时 / 播完本集 / 自定义时长），以便睡前定时。
49. 作为用户，我想倒计时中可取消或重选（重选为替换、不叠加），到点只暂停不退出，且剩余时间不在通知栏和界面显示，以便不打扰。
50. 作为用户，我想音频起播与跳转后有 500ms 淡入，以便不被突兀的爆音惊到。
51. 作为用户，我想拔出耳机或蓝牙断开时立即暂停且不自动恢复，以便公共场所不外放。
52. 作为用户，我想视频和音频的播放进度都被记住（应用重启后仍在），以便接着看。
53. 作为用户，我想只有完整播放到 100% 才算看完并清除进度，中途退出都保留，以便不会丢进度。
54. 作为用户，我想全局设置“始终从头播放 / 播放上次位置”，以便按习惯选择。
55. 作为用户，我想进入目录时自动回到上次停留的位置（可设置开关，默认开），以便继续上次的浏览。
56. 作为用户，我想目录位置按连接源与目录分别记录，且与播放进度互不影响，以便浏览和续播各自独立。
57. 作为用户，我想删除文件时其进度记录一并删除，以便记录不留垃圾。
58. 作为用户，我想播放页沉浸式全屏（无系统栏、适配刘海与手势导航），以便最大化画面。
59. 作为用户，我想设置“后台播放”开关，开时退到后台音频继续、画面停止渲染，关时退到后台立即暂停，以便按场景选择。

## Implementation Decisions

（每条对应 ADR，实现时以 ADR 为准）

- **技术栈**：Kotlin + Jetpack Compose；minSdk 26 / targetSdk 35（ADR-0001）。
- **播放核心**：libmpv，集成路线基于 mpv-android 官方构建产物；渲染用 libmpv 的 Surface 挂载（OpenGL→Surface）嵌入 Compose AndroidView；版本锁定（ADR-0006/0019）。
- **进程模型**：单一 PlaybackService（前台服务）持有 mpv 实例与 MediaSession，Activity 仅绑定；通知栏控制由 MediaSession 提供（ADR-0009/0019）。
- **播放逻辑接缝**：`PlaybackController` 播放会话接口承载循环三态状态机、自动连播开关、“下一集恒按名称排序”、定时暂停、进度记忆决策、耳机断开暂停、淡入触发（ADR-0007/0011/0015/0016）。
- **媒体接缝**：`MediaFile` 统一抽象 + `MediaLibrary`；本地走 SAF（多根目录持久授权，不申请存储权限）；SMB 用 SMBJ（SMB2/3，禁 SMB1）；WebDAV 用 OkHttp 实现（PROPFIND/GET/Range）（ADR-0002/0020）。
- **导航与顶栏**：首页、源列表、库页面顶栏左侧统一为汉堡按钮（打开设置）；源列表与库页面不提供返回箭头。库页面顶栏右侧为视图与排序按钮。设置页返回进入前的界面。系统返回严格逐级回退，播放页关闭后回到进入前的导航屏。首页首次返回提示“再按一次退出”，2 秒内再按才退出。进程被回收后恢复当前屏、连接源、库目录栈与浏览位置，浏览位置恢复不受目录位置记忆开关影响；播放页不恢复（ADR-0022/0026）。
- **连接源模型**：统一保存名称、服务器地址、路径或起始目录、用户名；密码单独加密保存。名称可空，回退规则见 ADR-0022。表单只显示字段标题，不显示“可空”或括号说明。
- **SMB 与 WebDAV 浏览根**：SMB 路径为空时枚举共享作为根；WebDAV 从起始目录开始，起始目录为空时从服务器地址根目录开始（ADR-0002/0022）。
- **WebDAV 访问**：允许 `http://` 明文地址并在应用层开启明文流量；PROPFIND 的目录地址统一以 `/` 结尾，避免依赖服务器目录重定向（ADR-0002）。
- **列表与排序**：视图为列表 / 网格 2/3/4 列；排序为名称升序、名称降序、修改时间 新→旧、修改时间 旧→新；子目录恒在文件之前；视图与排序都在库页面顶栏提供（ADR-0010）。切换排序与长按排序按钮回到顶部；切换视图仍按目录位置记录定位（ADR-0023）。
- **目录位置记忆**：按连接源与相对目录记录第一个可见条目与偏移，进入目录时恢复；与播放进度分开（ADR-0023）。
- **字幕**：mpv 内部 libass 渲染；外挂字幕经 `sub-add` 加载；内嵌/外挂互斥；匹配规则为同目录同前缀，srt/ass（ADR-0008）。
- **手势**：左右各 18% 竖条上下拖动调系统媒体音量，中间 64% 左右拖动跳转（整屏宽对应 5 分钟）；中间双击暂停/继续，左右侧双击 ±10 秒。双击后在该侧显示 ◀◀ 或 ▶▶ 与下方累计秒数，并从屏幕同侧边缘向内扩散黑色半透明涟漪；3 秒内继续双击累计。拖动进度时屏幕正中显示大号目标时间与同字号白色增减量，无底板。单击显隐控制条并延迟到双击窗口结束；位移超过 9dp 才进入音量调整；顶栏与底部控制条不响应手势，面板打开时禁用手势；不提供亮度手势（ADR-0014/0025）。
- **播放页控制层**：顶栏与底栏透明，只在屏幕上下边缘保留极淡内渐变，不使用实色底。标题在左上角紧挨返回按钮，单行省略；右上角为转屏按钮与更多按钮，转屏按钮点击直接切横竖、只影响本次播放。底部三个传输热区等宽等高：总宽 186dp、各 62dp、高 58dp、彼此无间隙，图标保持 28dp/34dp；按下为铺满热区的白色方形涟漪，未按下无背景；字幕紧挨播放列表放在右下区域，播放列表在右下角，更多在右上角；未锁定时锁定按钮在左下角；锁定时只保留左上角白色解锁按钮，5 秒自动隐藏、点画面重现、点一次解锁。字幕按钮常显，使用官方 Material 字幕图标。控制层 5 秒无操作自动隐藏，任意操作重置计时，面板打开时不隐藏；显示与隐藏为 200ms 淡入淡出；控制层隐藏时已打开的面板一并关闭并清理状态，不得保留不可见但仍拦截手势的面板。“更多”面板无标题栏，所有选项以带勾选的列表呈现；更多与播放列表打开后均可点其它区域关闭。播放列表以低透明度渐变黑底从右侧滑出并占右半屏，打开时隐藏其它控制层，当前项自动居中，点左半屏关闭；播放列表非当前项文字与顶部计数标题为白色；编号至少两位、距抽屉左边缘 16dp（不叠加系统左 inset），编号到标题 16dp；当前项编号使用强调色，淡蓝底横跨整行、左右各 4dp 内缩，右侧为 11.5sp/16dp 的强调色 ▶。切集与恢复期间除上一集/下一集外，控件保持原亮度与外观，只拦截点击；首次打开仍按不可用外观置灰（返回入口除外）。视频未覆盖区域为纯黑。按钮图标整体放大，进度条使用圆形滑块，左侧当前时间、右侧总时长，时间距屏幕与轨道各 16dp、时间宽度贴合文字、触控高度 36dp、视觉轨道 2dp；拖动期间左右时间标签固定为两侧较大宽度，拖动结束恢复贴合文字（ADR-0025）。
- **播放列表与上下集**：播放列表选择按媒体位置解析目标，不把显示下标直接当作播放索引；上一集、下一集与列表选择共用同一套索引解析。切集需区分自然播完与播放被替换触发的事件，避免误触发连播。
- **缓冲与切集**：冷启动黑屏中央显示缓冲指示；从浏览页点入视频时进入播放页立即显示，不受 1000ms 延迟约束。切集暂停原视频并保留冻结画面，缓冲指示以透明叠层盖在其上，不铺黑底。切集在 1000ms 后才显示提示。浏览页点入的首次缓冲期间只允许返回；切集缓冲期间允许返回与上一集/下一集，其它控件保持原亮度、只拦截点击；连点上一集/下一集时目标实时前移，最终从目标集开始加载，不经过中间集。切集缓冲期间目标加载阶段除返回与上一集/下一集外全部禁用，恢复原片阶段额外允许播放/暂停。自动下一集与手动切集共用同一套切换与就绪判定；手动切集完成后自动播放，即使切集前暂停。就绪指新视频帧真正输出到 Surface；实现以播放位置前进作为证据，等不到时若已收到加载或画面信号，2 秒后按就绪收尾；暂停态回前台改由一次非 seek 刷新证明新帧。离屏抓帧只用于探测可解码，不作为切集完成信号；新帧持续不可得时冻结画面保留到 60 秒失败判定。播完由 mpv 的 `eof-reached` 判定，配合 `keep-open=yes` 停在末帧，不依据 `END_FILE` 猜测原因。失败取消切换并保持暂停，返回行为按场景区分；用户在恢复期间按过播放则恢复后继续，片尾恢复时从头播放；原位置在片尾时保持片尾不动，以文件加载完成作为就绪并黑底暂停；加载 60 秒无任何事件按失败处理；后台无可渲染画面时以文件加载完成作为就绪（ADR-0024）。
- **后台播放**：设置项“后台播放”默认开；开时退后台音频继续，回前台自动恢复画面并继续播放，Surface 重挂后若无新帧允许触发一次非 seek 刷新；关时退后台立即暂停，回前台保持暂停、通知栏播放键不恢复；回前台重新挂载 Surface，挂载幂等（ADR-0009/0019/0026）。
- **方向**：设置四选一，默认随系统；“跟随视频”监听宽高比变化旋转；竖屏视频视口居中。播放页转屏按钮始终生效，包括“跟随视频”模式，只覆盖本次播放。播放页控制层在横竖屏下使用同一套布局；竖屏时视频居中、上下为纯黑（ADR-0013/0025）。
- **音频**：起播与 seek 后 500ms 淡入；监听系统耳机断开广播立即暂停（ADR-0016）。
- **持久化**：Room 存进度记录（以媒体路径为唯一键：位置、时长、修改时间）；连接源书签与目录位置记忆用 DataStore；密码入 EncryptedSharedPreferences；设置用 DataStore，包含后台播放开关与诊断日志开关（ADR-0018/0028）。
- **缩略图**：本地视频按比例抽取多帧（不超过 3 帧）；网络源只取 max(1% 时长, 1 秒) 处 1 帧，时长未知时取 1 秒，不合格时保持占位图。跳过纯黑/纯色帧；本地全部不合格时退到约 33% 处。时长未知时改用固定候选位置，最后一个作为兜底；所有候选都不可用时保持占位图。抽帧结果先缩放到 320–512px 宽（网络目标宽 320）再压 JPEG 80–85，不缓存全尺寸帧。缓存键包含位置、大小、修改时间、抽帧策略版本与目标宽度；修改时间缺失时退化为大小加有效期。本地并发 2、网络并发 2，同键请求去重，缓存命中时复用已记录的时长。网络不单独读取时长，也不把时长写入缩略图结果。抽取失败按 30 秒起、10 分钟封顶退避；无图条目仍记录时长；策略版本变化允许首次冷抽。缓存容量 128–256MB，LRU 清理。进入目录后可见项优先，前后各预取 1–2 行，离屏取消，排队任务开始前复查范围、离开范围直接放弃；网络可见项按从上到下顺序出图，平均每个不超过 1 秒，慢源保持占位图且不阻塞其它条目；不使用系统级后台任务预生成（ADR-0017/0027）。
- **视觉规范**：首页入口与源列表条目共用卡片规格（外宽 328dp、圆角 20dp、图标 48dp、上下内边距 18dp、左右内边距 16dp）；设置行最小高度 52dp，开关 44×26，右侧控件同一基准线，弹出选项右对齐。浏览页列表边距为 8dp、缩略图为 98×57，比现状更宽；只有浏览页条目点击显示白色涟漪，其它入口与按钮不显示。浏览列表与网格不显示类型说明（ADR-0025/0029）。
- **后台恢复画面**：退后台时若处于暂停，先缓存当前帧再分离 Surface；回前台先显示缓存帧，等 mpv 输出新帧后撤掉。播放中退后台不截帧，回前台自动恢复画面并继续播放。不采用强制 seek；Surface 重挂后若无新帧，允许触发一次非 seek 刷新。关闭后台播放时回前台只显示暂停帧，不自动继续（ADR-0009/0026）。
- **通知栏媒体控制**：标题为去掉扩展名的文件名，总时长写入媒体元数据；封面取自缩略图缓存，取不到时用应用图标，并通过文件提供器暴露给系统。播放中约每秒刷新一次进度，支持系统拖动定位。后台播放关闭时仍只保留暂停动作（ADR-0028）。
- **诊断日志**：设置项默认关闭；开启后写轮转文件，单文件 2MB、最多 3 个。记录生命周期、播放状态迁移、加载/切集/失败、播放核心错误文本与目标文件标识、60 秒看门狗触发、Surface 重挂与恢复结果、缩略图抽取失败、导航跳转与未捕获异常堆栈；不记录密码。导出为 txt 并通过系统分享面板发送，内容包含应用版本、设备型号与系统版本。Java 崩溃由全局未捕获异常处理器写入；后台连接线程在边界捕获 `RuntimeException`/`Throwable`，网络读超时按连接失败收尾，不得终止进程；原生崩溃只保留 mpv 日志，不提示“上次异常退出”（ADR-0028）。
- **浏览页即时跳转**：点击视频后立即显示黑屏与“正在缓冲”并进入播放页；目录枚举与网络探测移到后台，不阻塞跳转；加载失败自动回列表并提示（ADR-0029）。
- **应用图标**：白底 + 蓝色播放三角；108 视口内三角缩小 20%，按视觉重心居中（ADR-0004）。
- **交付分期**：MVP 含首页连接源管理、网络源与外挂字幕；第 2 期含定时/淡入/耳机/后台/目录位置记忆；第 3 期打磨（ADR-0005）。

## Testing Decisions

- **只测外部行为**：通过接缝驱动、断言可观察结果，不测实现细节。
- **接缝 1（PlaybackController）**：注入 fake 播放引擎 + 假时钟，覆盖循环三态状态机、自动连播开关两种取值、“下一集”恒按名称排序、定时暂停到点暂停/重选替换、“播完本集”、100% 清进度 vs 中途保留、耳机断开即暂停、淡入在起播/seek 时被触发；切集时暂停原视频、1000ms 缓冲提示阈值、新帧上屏后才撤冻结画面、失败取消并保持暂停、缓冲期返回取消；切集缓冲期间连点上一集/下一集时目标实时前移且不经过中间集；自动下一集由 `eof-reached` 触发、与手动切集走同一套切换与就绪判定；手动切集完成后自动播放（含切集前暂停）；播放列表与上下集按媒体位置解析，替换事件不触发自然连播；退后台暂停时缓存帧、回前台先显示缓存帧；后台播放开启时回前台继续播放，关闭时保持暂停。
- **接缝 2（MediaLibrary）**：注入 fake 文件树（含本地/模拟网络节点），覆盖目录即列表、名称/时间排序、外挂字幕匹配评分，以及 SMB 路径为空时的共享枚举根、WebDAV 起始目录根。自然排序为表驱动纯函数测试（`2`<`10`、大小写、混合数字段等 Windows 语义用例）。
- **接缝 3（连接源仓库与库状态）**：覆盖新增/编辑/删除连接源、名称回退、保存后连接源立即出现在列表、本地源不可编辑、删除只移除本地记录、删除连接源清理位置记录。
- **接缝 4（设置状态）**：覆盖解码/起播位置/目录位置开关/后台播放开关的取值与持久化读回，以及用户可见文案与选项顺序；视图与排序不再由设置页提供。
- **接缝 5（目录位置记忆）**：覆盖按连接源与目录分别记录、恢复第一个可见条目与偏移、关闭开关后从顶部开始、条目不存在时停在末尾、切换排序回到顶部、切换视图仍按记录定位、与播放进度互不影响。
- **接缝 6（导航状态）**：覆盖子目录到源列表到首页的严格逐级回退、设置页返回来处、首页二次返回窗口、播放页关闭后回到进入前屏幕；模拟进程回收后恢复当前屏、连接源、库目录栈与浏览位置，且播放页不恢复。
- **接缝 7（WebDAV 地址与请求）**：覆盖 `http://` 与 `https://` 地址、端口默认值、起始目录、PROPFIND 目录地址末尾斜杠；用 fake transport 断言实际请求地址。
- **接缝 8（缩略图）**：覆盖本地多帧抽样与黑帧/纯色判定、全部不合格时退到 33%、网络取 max(1% 时长, 1 秒) 处单帧（时长未知取 1 秒）、缩放后写入缓存、网络目标宽 320、缓存键包含大小/修改时间/策略版本/目标宽度、同键请求去重、本地与网络并发上限均为 2、网络不读取时长、抽取失败保持占位图、成功后就绪替换、可见项按顺序出图与离屏取消。
- **接缝 9（诊断日志）**：注入内存日志出口，覆盖开关关闭时不写入、开启后记录生命周期与播放状态迁移、异常堆栈写入、导出内容为纯文本且不含密码并包含版本与设备信息；连接线程收到 `RuntimeException` 时按失败收尾而不终止进程。
- **接缝 10（媒体会话）**：注入播放状态与当前媒体，覆盖标题为去扩展名文件名、总时长、封面回退、播放中约每秒刷新位置、后台播放关闭时动作只剩暂停。
- **接缝 11（播放页界面状态）**：覆盖控制层 5 秒自动隐藏与操作重置计时、隐藏/显示的淡入淡出状态、切集期间控件保持可用外观但拦截点击、面板互斥与点外部关闭、播放列表打开时当前项定位、双击提示 3 秒累计；只测状态与计时，不做像素或截图对比。
- **先例**：现有 `SettingsViewModelTest`、`LibraryStateTest`、`NetworkSourceRepositoryTest`、`WebDavStreamsTest`、`CachedMediaPreviewSourceTest` 等按接缝注入 fake 的写法，新增测试沿用。
- **不做**：mpv/FFmpeg/SMBJ 等第三方库行为不测；Compose UI 仅关键路径冒烟（首页入口、源列表、库页面、设置项、播放控制条），不纳入验收标准。

## Out of Scope

- 在线字幕下载、弹幕、投屏（DLNA/Cast）、画中画、倍速播放、均衡器/音效、HLS/DASH 在线流媒体协议、视频转码、桌面/iOS 版本、SMB1、上架应用商店。
- 列表内拖拽手动排序（排序只按名称/时间）。
- 连接源导入/导出、跨设备同步、多选批量删除、连接源排序与分组。
- 亮度手势与窗口亮度调节（亮度始终跟随系统）。
- 服务端缩略图、预生成封面、整文件下载后再抽帧。
- 预加载多个待播条目；切集只缓冲目标条目。
- 手势分区宽度、拖动灵敏度、双击窗口的自定义设置。
