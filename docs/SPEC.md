# Spec: CC Player MVP

> 状态：草稿（未发布到 GitHub Issues）。发布时打 `ready-for-agent` 标签。
> 依据：需求访谈共识 + `GLOSSARY.md` + `docs/adr/0001~0021`。

## Problem Statement

用户在安卓上看本地与 NAS（SMB/WebDAV）里的视频和音频，现有播放器要么格式/字幕支持不全（尤其 mkv 内 ASS 字幕渲染差），要么不能自由切换硬/软解、不能方便地连播/循环/在播放器内切换剧集，也不记住播放位置。用户希望有一个格式覆盖全、字幕渲染好、列表好整理、播放行为可控（连播/循环/定时/锁定/后台）的播放器。

## Solution

CC Player（`com.cc3301.ccplayer`）：以 libmpv（FFmpeg + libass）为播放核心的安卓播放器。本地媒体通过 SAF 选目录管理，网络源由应用层 SMB2/3 与 WebDAV 客户端经统一媒体文件抽象接入；列表支持 Windows 自然排序与 2/3/4 网格；播放器支持拖动进度、分区双击、亮度/音量手势、锁定、上下集、定时暂停、播放列表、三态循环与自动连播开关；内嵌/外挂字幕互斥可切；进度记忆（100% 播完才清除）支持续播与列表自动滚动（可开关）；沉浸式全屏；退后台音频继续。Logo：白底蓝色播放三角。

## User Stories

1. 作为用户，我想播放本地视频（mp4、mkv、webm、avi、mov、flv、ts、wmv），以便无需转码直接观看。
2. 作为用户，我想播放本地音频（mp3、opus、wav、flac、m4a、aac、ogg），以便统一管理音乐与有声内容。
3. 作为用户，我想播放 mkv 内嵌的 ASS 字幕并完整渲染样式，以便字幕与桌面播放器观感一致。
4. 作为用户，我想播放 mkv 内嵌的 SRT 字幕，以便纯文本字幕正常显示。
5. 作为用户，我想在存在内嵌字幕时默认只加载内嵌字幕、外挂字幕不自动加载但可在菜单中手动开启，以便可控地选择字幕来源。
6. 作为用户，我开启外挂字幕时内嵌字幕停止显示（任一时刻只有一路字幕生效），以便不叠字。
7. 作为用户，我想在播放器菜单里看到内嵌轨道、可匹配的外挂字幕与关闭三项，以便随时切换。
8. 作为用户，我想默认硬解、解码失败自动回退软解，以便流畅且兜底可靠。
9. 作为用户，我想在设置里全局选硬解/软解，并在播放器控制条上对当前会话快捷切换，以便个别格式硬解异常（绿屏/花屏）时立即自救。
10. 作为用户，我想添加 SMB 网络源（SMB2/3，不支持 SMB1）并保存服务器与凭据，以便直接浏览 NAS 媒体。
11. 作为用户，我想添加 WebDAV 网络源并保存地址与凭据，以便直接浏览网盘/NAS 媒体。
12. 作为用户，我想本地与网络源在同一套列表/排序/播放体验下工作，以便不因来源不同改变习惯。
13. 作为用户，我想用单列列表或 2/3/4 列网格浏览媒体目录，以便按内容密度切换视图。
14. 作为用户，我想按名称排序且规则与 Windows 资源管理器一致（数字按数值、不分大小写，如 `2` 在 `10` 前），以便剧集顺序与电脑上相同。
15. 作为用户，我想按修改时间排序，以便快速找到最新下载的内容。
16. 作为用户，我想网格卡片显示缩略图、文件名与时长角标，以便一眼识别。
17. 作为用户，我想音频卡片显示文件内嵌封面（无封面用音符占位图），以便音乐库更直观。
18. 作为用户，我想屏幕方向设置四选一：屏幕方向（默认，随系统）/ 横屏 / 竖屏 / 跟随视频，以便适配不同内容。
19. 作为用户，我想"跟随视频"按宽高比判定方向（≥1 横、<1 竖），且播放中随比例变化旋转，以便混比例内容正确显示。
20. 作为用户，我想横向拖动调整进度且拖动中显示预览时间气泡、松手才生效，以便精确定位不误触。
21. 作为用户，我想左半屏上下拖调亮度、右半屏上下拖调音量，以便单手调节。
22. 作为用户，我想双击左 1/3 倒退 10s、中间暂停/继续、右 1/3 前进 10s，以便快速微调。
23. 作为用户，我想锁定播放器后所有手势失效、再点锁按钮确认才解锁，以便口袋误触不打断播放。
24. 作为用户，我想当前文件播完自动播下一个（顺序播放到末尾停止），以便追剧不用点屏幕。
25. 作为用户，我想设置"自动播放下一个"开关，关闭时顺序/列表循环播完即停，以便挂机时不想让它继续。
26. 作为用户，我想单集循环，以便重复学习/听歌。
27. 作为用户，我想列表循环（末尾回第一个，配合自动连播），以便歌单/剧集无限续。
28. 作为用户，我想"上一集/下一集"始终按名称自然排序的相邻文件（与当前视图排序无关），以便连播顺序稳定可预期。
29. 作为用户，我想当前目录即播放列表（也可跨目录手动追加），以便零配置连播。
30. 作为用户，我想在播放器内打开播放列表并点击切换，以便不退出播放页选片。
31. 作为用户，我想定时暂停（10 分钟 / 30 分钟 / 1 小时 / 2 小时 / 播完本集 / 自定义时长），以便睡前定时。
32. 作为用户，我想倒计时中可取消或重选（重选为替换、不叠加），到点只暂停不退出，且剩余时间不在通知栏和界面显示，以便不打扰。
33. 作为用户，我想音频起播与跳转后有 500ms 淡入，以便不被突兀的爆音惊到。
34. 作为用户，我想拔出耳机或蓝牙断开时立即暂停且不自动恢复，以便公共场所不外放。
35. 作为用户，我想视频和音频的播放进度都被记住（应用重启后仍在），以便接着看。
36. 作为用户，我想只有完整播放到 100% 才算看完并清除进度，中途退出都保留，以便不会丢进度。
37. 作为用户，我想全局设置"始终从头播放 / 播放上次位置"，以便按习惯选择。
38. 作为用户，我想进入列表时自动滚动到上次播放的位置（可设置开关，默认开），以便快速续看。
39. 作为用户，我想删除文件时其进度记录一并删除，以便记录不留垃圾。
40. 作为用户，我想播放页沉浸式全屏（无系统栏、适配刘海与手势导航），以便最大化画面。
41. 作为用户，我想退出到后台后音频继续、画面停止渲染，回前台恢复，以便挂机听。
42. 作为用户，我想通知栏媒体控制（播放/暂停/上一集/下一集），以便不进 App 也能控制。

## Implementation Decisions

（每条对应 ADR，实现时以 ADR 为准）

- **技术栈**：Kotlin + Jetpack Compose；minSdk 26 / targetSdk 35（ADR-0001）。
- **播放核心**：libmpv，集成路线基于 mpv-android 官方构建产物；渲染用 MPVView（OpenGL→Surface）嵌入 Compose AndroidView；版本锁定（ADR-0006/0019）。
- **进程模型**：单一 PlaybackService（前台服务）持有 mpv 实例与 MediaSession，Activity 仅绑定；通知栏控制由 MediaSession 提供（ADR-0009/0019）。
- **播放逻辑接缝**：`PlaybackController` 播放会话接口承载循环三态状态机、自动连播开关、"下一集恒按名称排序"、定时暂停、进度记忆决策、耳机断开暂停、淡入触发（ADR-0007/0011/0015/0016）。
- **媒体接缝**：`MediaFile` 统一抽象 + `MediaLibrary`；本地走 SAF（多根目录持久授权，不申请存储权限）；SMB 用 SMBJ（SMB2/3，禁 SMB1）；WebDAV 用 OkHttp 实现（PROPFIND/GET/Range）（ADR-0002/0020）。
- **排序**：名称排序实现 Windows `StrCmpLogicalW` 等价自然排序，为纯函数（ADR-0010）。
- **字幕**：mpv 内部 libass 渲染；外挂字幕经 `sub-add` 加载；内嵌/外挂互斥；匹配规则为同目录同前缀，srt/ass（ADR-0008）。
- **手势**：横向拖进度（气泡预览、松手生效）、左右半屏亮度/音量、双击三分区（−10s/暂停/+10s）、锁定禁用手势（ADR-0014）。
- **方向**：设置四选一，默认随系统；"跟随视频"监听宽高比变化旋转；竖屏视频视口居中（ADR-0013）。
- **音频**：起播与 seek 后 500ms 淡入；监听系统耳机断开广播立即暂停（ADR-0016）。
- **持久化**：Room 存进度记录（以媒体路径为唯一键：位置、时长、修改时间）与网络源书签（密码入 EncryptedSharedPreferences）；设置用 DataStore；排序/视图/方向/解码/连播开关/续播模式/自动滚动开关均为持久设置（ADR-0018）。
- **缩略图**：本地视频 MediaMetadataRetriever 抽帧、音频提取内嵌封面，Coil 磁盘缓存 LRU；网络文件占位图（ADR-0017/0021）。
- **交付分期**：MVP 一次性含网络源与外挂字幕；第 2 期=定时/淡入/耳机/后台/自动滚动（本 spec 涵盖 MVP 全量，第 2 期功能随之实现），第 3 期打磨（ADR-0005）。

## Testing Decisions

- **只测外部行为**：通过接缝驱动、断言可观察结果，不测实现细节。
- **接缝 1（PlaybackController）**：注入 fake 播放引擎 + 假时钟，覆盖：循环三态状态机、自动连播开关两种取值、"下一集"恒按名称排序、定时暂停到点暂停/重选替换、"播完本集"、100% 清进度 vs 中途保留、耳机断开即暂停、淡入在起播/seek 时被触发。本仓库无既有测试，这些是第一批测试，采用 JUnit + 协程测试标准库，无 UI。
- **接缝 2（MediaLibrary）**：注入 fake 文件树（含本地/模拟网络节点），覆盖：目录即列表、名称/时间排序、外挂字幕匹配评分（同名前缀、多语言后缀得分）。自然排序为表驱动纯函数测试（`2`<`10`、大小写、混合数字段等 Windows 语义用例）。
- **不做**：mpv/FFmpeg/SMBJ 等第三方库行为不测；Compose UI 仅关键路径冒烟（列表渲染、控制条出现），不纳入验收标准。

## Out of Scope

- 在线字幕下载、弹幕、投屏（DLNA/Cast）、画中画、倍速播放、均衡器/音效、HLS/DASH 在线流媒体协议、视频转码、桌面/iOS 版本、SMB1、上架应用商店。
- 列表内拖拽手动排序（排序只按名称/时间）。
