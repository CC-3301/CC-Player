# Spec: CC Player MVP

## Problem Statement

用户在安卓上看本地与 NAS（SMB/WebDAV）里的视频和音频，现有播放器要么格式/字幕支持不全（尤其 mkv 内 ASS 字幕渲染差），要么不能自由切换解码方式、不能方便地连播/循环/在播放器内切换剧集，也不记住播放位置。

来源入口也分散：本地目录、SMB、WebDAV 的连接操作混在媒体库顶栏，添加网络源后看不到新内容；视图与排序散落在库页面，设置缺少统一入口。用户希望打开应用先选择从哪里看，连接与设置都集中管理。

## Solution

CC Player（`com.cc3301.ccplayer`）：以 libmpv（FFmpeg + libass）为播放核心的安卓播放器。

首页只有本地、SMB、WebDAV 三个协议入口与左上角设置齿轮，标题居中显示 CC Player。每个入口管理该协议的连接源，可新增、编辑、删除；连接源保存名称、服务器地址、路径或起始目录与可选凭据。本地来源通过 SAF 选择文件夹；SMB 路径为空时列出服务器共享；WebDAV 从起始目录开始浏览。

选择连接源进入统一的库页面，顶栏只有返回与当前目录名。列表支持列表视图与 2/3/4 列网格，排序支持名称与修改时间，子目录恒排在文件之前。进入目录可回到上次停留的位置。

播放器支持拖动进度、分区双击、亮度/音量手势、锁定、上下集、定时暂停、播放列表、三态循环与自动连播开关；内嵌/外挂字幕互斥可切；进度记忆（100% 播完才清除）支持续播；沉浸式全屏；退后台音频继续。

图标为白底蓝色播放三角；自适应图标中三角缩小 20% 并按视觉重心居中。

## User Stories

1. 作为用户，我想播放本地视频（mp4、mkv、webm、avi、mov、flv、ts、wmv），以便无需转码直接观看。
2. 作为用户，我想播放本地音频（mp3、opus、wav、flac、m4a、aac、ogg），以便统一管理音乐与有声内容。
3. 作为用户，我想播放 mkv 内嵌的 ASS 字幕并完整渲染样式，以便字幕与桌面播放器观感一致。
4. 作为用户，我想播放 mkv 内嵌的 SRT 字幕，以便纯文本字幕正常显示。
5. 作为用户，我想外挂字幕自动加载、内嵌字幕优先显示（没有内嵌时才默认用外挂），以便开箱就有字幕、又能优先用片源自带的。
6. 作为用户，我开启外挂字幕时内嵌字幕停止显示（任一时刻只有一路字幕生效），以便不叠字。
7. 作为用户，我想在播放器菜单里看到内嵌轨道、可匹配的外挂字幕与关闭三项，以便随时切换。
8. 作为用户，我想默认硬件解码、解码失败自动回退软件解码，以便流畅且兜底可靠。
9. 作为用户，我想在设置里全局选择硬件解码或软件解码，并在播放器控制条上对当前会话快捷切换，以便个别格式硬解异常（绿屏/花屏）时立即自救。
10. 作为用户，我想打开应用先看到首页，只有本地、SMB、WebDAV 三个来源入口，以便快速决定从哪里开始。
11. 作为用户，我想首页左上角有设置齿轮、标题居中出现，以便随时进入设置并确认当前应用。
12. 作为用户，我想首页三个入口只显示图标与名称，以便界面保持简洁。
13. 作为用户，我想点击某个协议入口后看到该协议的连接源列表，以便集中管理同类来源。
14. 作为用户，我想源列表只显示连接源名称，以便快速识别已有连接。
15. 作为用户，我想源列表右下角有加号按钮，以便随时新增连接。
16. 作为用户，我想在没有连接源时看到空状态提示，但加号仍可用，以便知道下一步该做什么。
17. 作为用户，我想新增 SMB 连接时填写名称、服务器地址、路径、用户名与密码，以便连接局域网共享。
18. 作为用户，我想 SMB 服务器地址不填端口时默认 445，以便少填一项。
19. 作为用户，我想 SMB 路径可以只填共享名，也可以填共享名加子目录，以便直接进入常用目录。
20. 作为用户，我想 SMB 路径留空时列出服务器上的共享，以便不知道共享名时也能浏览。
21. 作为用户，我想新增 WebDAV 连接时填写名称、服务器地址、起始目录、用户名与密码，以便连接网盘或 NAS。
22. 作为用户，我想 WebDAV 地址不写端口时，http 默认 80、https 默认 443，以便少填一项。
23. 作为用户，我想 WebDAV 起始目录可空，为空时从服务器地址根目录开始，以便按需缩小浏览范围。
24. 作为用户，我想连接源名称可空，留空时 SMB/WebDAV 使用服务器地址、本地使用文件夹名，以便不想命名时也能保存。
25. 作为用户，我想编辑已保存的 SMB/WebDAV 连接，以便修改地址、路径或凭据。
26. 作为用户，我想删除连接前二次确认，且只删除本地记录与凭据、不删远程文件，以便避免误操作。
27. 作为用户，我想本地来源通过系统文件夹选择器添加，并且可以添加多个文件夹，以便管理不同磁盘位置。
28. 作为用户，我想本地连接源只提供删除，不提供编辑，以便操作符合它没有凭据的事实。
29. 作为用户，我想保存连接后它立即出现在源列表，以便确认保存成功。
30. 作为用户，我想点击连接源进入库页面，以便浏览该来源的根目录。
31. 作为用户，我想库页面顶栏只保留返回与当前目录名，以便内容区域更干净。
32. 作为用户，我想在设置里切换列表视图与 2/3/4 列网格，以便按内容密度选择展示方式。
33. 作为用户，我想排序与视图只出现在设置页，以便库页面不再堆叠菜单。
34. 作为用户，我想按名称排序且规则与 Windows 资源管理器一致（数字按数值、不分大小写，如 `2` 在 `10` 前），以便剧集顺序与电脑上相同。
35. 作为用户，我想排序选项为名称升序、名称降序、修改时间 新→旧、修改时间 旧→新，以便按不同需求整理目录。
36. 作为用户，我想子目录恒排在文件之前，以便目录结构稳定可预期。
37. 作为用户，我想网格卡片显示缩略图、文件名与时长角标，以便一眼识别。
38. 作为用户，我想音频卡片显示文件内嵌封面（无封面用音符占位图），以便音乐库更直观。
39. 作为用户，我想屏幕方向设置四选一：屏幕方向（默认，随系统）/ 横屏 / 竖屏 / 跟随视频，以便适配不同内容。
40. 作为用户，我想“跟随视频”按宽高比判定方向（≥1 横、<1 竖），且播放中随比例变化旋转，以便混比例内容正确显示。
41. 作为用户，我想横向拖动调整进度且拖动中显示预览时间气泡、松手才生效，以便精确定位不误触。
42. 作为用户，我想左半屏上下拖调亮度、右半屏上下拖调音量，以便单手调节。
43. 作为用户，我想双击左 1/3 倒退 10s、中间暂停/继续、右 1/3 前进 10s，以便快速微调。
44. 作为用户，我想锁定播放器后所有手势失效、再点锁按钮确认才解锁，以便口袋误触不打断播放。
45. 作为用户，我想当前文件播完自动播下一个（顺序播放到末尾停止），以便追剧不用点屏幕。
46. 作为用户，我想设置“自动播放下一个”开关，关闭时顺序/列表循环播完即停，以便挂机时不想让它继续。
47. 作为用户，我想单集循环，以便重复学习/听歌。
48. 作为用户，我想列表循环（末尾回第一个，配合自动连播），以便歌单/剧集无限续。
49. 作为用户，我想“上一集/下一集”始终按名称自然排序的相邻文件（与当前视图排序无关），以便连播顺序稳定可预期。
50. 作为用户，我想当前目录即播放列表，以便零配置连播。
51. 作为用户，我想在播放器内打开播放列表并点击切换，以便不退出播放页选片。
52. 作为用户，我想定时暂停（10 分钟 / 30 分钟 / 1 小时 / 2 小时 / 播完本集 / 自定义时长），以便睡前定时。
53. 作为用户，我想倒计时中可取消或重选（重选为替换、不叠加），到点只暂停不退出，且剩余时间不在通知栏和界面显示，以便不打扰。
54. 作为用户，我想音频起播与跳转后有 500ms 淡入，以便不被突兀的爆音惊到。
55. 作为用户，我想拔出耳机或蓝牙断开时立即暂停且不自动恢复，以便公共场所不外放。
56. 作为用户，我想视频和音频的播放进度都被记住（应用重启后仍在），以便接着看。
57. 作为用户，我想只有完整播放到 100% 才算看完并清除进度，中途退出都保留，以便不会丢进度。
58. 作为用户，我想全局设置“始终从头播放 / 播放上次位置”，以便按习惯选择。
59. 作为用户，我想进入目录时自动回到上次停留的位置（可设置开关，默认开），以便继续上次的浏览。
60. 作为用户，我想目录位置按连接源与目录分别记录，且与播放进度互不影响，以便浏览和续播各自独立。
61. 作为用户，我想删除文件时其进度记录一并删除，以便记录不留垃圾。
62. 作为用户，我想播放页沉浸式全屏（无系统栏、适配刘海与手势导航），以便最大化画面。
63. 作为用户，我想退出到后台后音频继续、画面停止渲染，回前台恢复，以便挂机听。
64. 作为用户，我想通知栏媒体控制（播放/暂停/上一集/下一集），以便不进 App 也能控制。
65. 作为用户，我想应用图标在启动器裁切后三角大小适中且不偏左，以便桌面识别清晰。

## Implementation Decisions

（每条对应 ADR，实现时以 ADR 为准）

- **技术栈**：Kotlin + Jetpack Compose；minSdk 26 / targetSdk 35（ADR-0001）。
- **播放核心**：libmpv，集成路线基于 mpv-android 官方构建产物；渲染用 MPVView（OpenGL→Surface）嵌入 Compose AndroidView；版本锁定（ADR-0006/0019）。
- **进程模型**：单一 PlaybackService（前台服务）持有 mpv 实例与 MediaSession，Activity 仅绑定；通知栏控制由 MediaSession 提供（ADR-0009/0019）。
- **播放逻辑接缝**：`PlaybackController` 播放会话接口承载循环三态状态机、自动连播开关、“下一集恒按名称排序”、定时暂停、进度记忆决策、耳机断开暂停、淡入触发（ADR-0007/0011/0015/0016）。
- **媒体接缝**：`MediaFile` 统一抽象 + `MediaLibrary`；本地走 SAF（多根目录持久授权，不申请存储权限）；SMB 用 SMBJ（SMB2/3，禁 SMB1）；WebDAV 用 OkHttp 实现（PROPFIND/GET/Range）（ADR-0002/0020）。
- **首页与连接源**：独立首页、源列表、库页面与设置页；首页三入口，源列表增删改，库页面顶栏只留返回与目录名（ADR-0022）。
- **连接源模型**：统一保存名称、服务器地址、路径或起始目录、用户名；密码单独加密保存。名称可空，回退规则见 ADR-0022。
- **SMB 与 WebDAV 浏览根**：SMB 路径为空时枚举共享作为根；WebDAV 从起始目录开始，起始目录为空时从服务器地址根目录开始（ADR-0002/0022）。
- **列表与排序**：视图为列表 / 网格 2/3/4 列；排序为名称升序、名称降序、修改时间 新→旧、修改时间 旧→新；子目录恒在文件之前；视图与排序只在设置页（ADR-0010）。
- **目录位置记忆**：按连接源与相对目录记录第一个可见条目与偏移，进入目录时恢复；与播放进度分开（ADR-0023）。
- **字幕**：mpv 内部 libass 渲染；外挂字幕经 `sub-add` 加载；内嵌/外挂互斥；匹配规则为同目录同前缀，srt/ass（ADR-0008）。
- **手势**：横向拖进度（气泡预览、松手生效）、左右半屏亮度/音量、双击三分区（−10s/暂停/+10s）、锁定禁用手势（ADR-0014）。
- **方向**：设置四选一，默认随系统；“跟随视频”监听宽高比变化旋转；竖屏视频视口居中（ADR-0013）。
- **音频**：起播与 seek 后 500ms 淡入；监听系统耳机断开广播立即暂停（ADR-0016）。
- **持久化**：Room 存进度记录（以媒体路径为唯一键：位置、时长、修改时间）；连接源书签与目录位置记忆用 DataStore；密码入 EncryptedSharedPreferences；设置用 DataStore（ADR-0018）。
- **缩略图**：本地视频 MediaMetadataRetriever 抽帧、音频提取内嵌封面，Coil 磁盘缓存 LRU；网络文件占位图（ADR-0017/0021）。
- **应用图标**：白底 + 蓝色播放三角；108 视口内三角缩小 20%，按视觉重心居中（ADR-0004）。
- **交付分期**：MVP 含首页连接源管理、网络源与外挂字幕；第 2 期含定时/淡入/耳机/后台/目录位置记忆；第 3 期打磨（ADR-0005）。

## Testing Decisions

- **只测外部行为**：通过接缝驱动、断言可观察结果，不测实现细节。
- **接缝 1（PlaybackController）**：注入 fake 播放引擎 + 假时钟，覆盖循环三态状态机、自动连播开关两种取值、“下一集”恒按名称排序、定时暂停到点暂停/重选替换、“播完本集”、100% 清进度 vs 中途保留、耳机断开即暂停、淡入在起播/seek 时被触发。
- **接缝 2（MediaLibrary）**：注入 fake 文件树（含本地/模拟网络节点），覆盖目录即列表、名称/时间排序、外挂字幕匹配评分，以及 SMB 路径为空时的共享枚举根、WebDAV 起始目录根。自然排序为表驱动纯函数测试（`2`<`10`、大小写、混合数字段等 Windows 语义用例）。
- **接缝 3（连接源仓库与库状态）**：覆盖新增/编辑/删除连接源、名称回退、保存后连接源立即出现在列表、本地源不可编辑、删除只移除本地记录、删除连接源清理位置记录。
- **接缝 4（设置状态）**：覆盖视图/排序/解码/目录位置开关的取值与持久化读回，以及用户可见文案与选项顺序。
- **接缝 5（目录位置记忆）**：覆盖按连接源与目录分别记录、恢复第一个可见条目与偏移、关闭开关后从顶部开始、条目不存在时停在末尾、与播放进度互不影响。
- **先例**：现有 `SettingsViewModelTest`、`LibraryStateTest`、`NetworkSourceRepositoryTest`、`WebDavStreamsTest` 等按接缝注入 fake 的写法，新增测试沿用。
- **不做**：mpv/FFmpeg/SMBJ 等第三方库行为不测；Compose UI 仅关键路径冒烟（首页入口、源列表、库页面、设置项），不纳入验收标准。

## Out of Scope

- 在线字幕下载、弹幕、投屏（DLNA/Cast）、画中画、倍速播放、均衡器/音效、HLS/DASH 在线流媒体协议、视频转码、桌面/iOS 版本、SMB1、上架应用商店。
- 列表内拖拽手动排序（排序只按名称/时间）。
- 连接源导入/导出、跨设备同步、多选批量删除、连接源排序与分组。
