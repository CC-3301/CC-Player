# Spec: CC Player MVP

## Problem Statement

用户在安卓上看本地与 NAS（SMB/WebDAV）里的视频和音频，现有播放器要么格式/字幕支持不全（尤其 mkv 内 ASS 字幕渲染差），要么不能自由切换解码方式、不能方便地连播/循环/在播放器内切换剧集，也不记住播放位置。

播放界面布局不符合预期：控制项分散、按钮位置不固定、选项需要反复点击切换；手势区域过大，缺少进度拖动与双击暂停，容易误触。打开 SMB 大文件时长时间黑屏且没有任何反馈；切集时会闪一下上一个视频的画面；从后台回到前台会黑屏；上一集按钮点了没反应；播放列表点击会恒定偏移一项。

浏览与入口缺少统一规则：不同页面的入口与返回方式不一致，排序与视图离浏览现场太远，调整要来回跳；添加 WebDAV 源时明文 HTTP 地址连不上；网络视频缺少封面，只能显示占位图；设置页开关行与选项行宽度不一致，弹出选项靠左；点击还带白色涟漪。

## Solution

CC Player（`com.cc3301.ccplayer`）：以 libmpv（FFmpeg + libass）为播放核心的安卓播放器。

首页只有本地、SMB、WebDAV 三个协议入口，左上角汉堡按钮打开设置，标题居中显示 CC Player。源列表与库页面同样用汉堡按钮，离开靠系统返回；库页面顶栏右侧提供视图与排序。设置页左侧保留返回，回到进入前的界面。系统返回逐级回退，首页首次返回提示“再按一次退出”。

播放页底部控制条以图标呈现：播放/暂停严格居中，上一集在左，下一集与字幕在右，播放列表在右下角，更多在右上角，锁定在左上角返回按钮下方。解码、循环、方向、自动连播与定时都在“更多”的列表中选择。左右两侧竖条上下拖动调系统媒体音量，中间区域左右拖动跳转、双击暂停，左右侧双击分别后退/前进 10 秒。

首次打开媒体时黑屏中央显示转圈与“正在缓冲”；切集时暂停原视频并保留冻结画面，缓冲指示叠在原画面上，下一集首帧就绪后直接替换。两者都在 500ms 后才显示缓冲提示。缓冲失败取消切换并保持暂停。

列表与源列表只显示名称，不再写“文件夹 / 视频”说明；本地与网络视频都出封面。首页入口与源列表条目使用同一套卡片规格；设置页行高与右侧控件对齐，弹出选项靠右；全局去掉点击涟漪。

WebDAV 支持 `http://` 明文地址，目录请求补末尾斜杠。后台播放提供开关；关闭时退到后台立即暂停。

图标为白底蓝色播放三角；自适应图标中三角缩小 20% 并按视觉重心居中。

## User Stories

1. 作为用户，我想播放本地视频（mp4、mkv、webm、avi、mov、flv、ts、wmv），以便无需转码直接观看。
2. 作为用户，我想播放本地音频（mp3、opus、wav、flac、m4a、aac、ogg），以便统一管理音乐与有声内容。
3. 作为用户，我想播放 mkv 内嵌的 ASS 字幕并完整渲染样式，以便字幕与桌面播放器观感一致。
4. 作为用户，我想播放 mkv 内嵌的 SRT 字幕，以便纯文本字幕正常显示。
5. 作为用户，我想外挂字幕自动加载、内嵌字幕优先显示（没有内嵌时才默认用外挂），以便开箱就有字幕、又能优先用片源自带的。
6. 作为用户，我开启外挂字幕时内嵌字幕停止显示（任一时刻只有一路字幕生效），以便不叠字。
7. 作为用户，我想在播放器菜单里看到内嵌轨道、可匹配的外挂字幕与关闭三项，以便随时切换。
8. 作为用户，我想默认硬件解码、解码失败自动回退软件解码，以便流畅且兜底可靠。
9. 作为用户，我想在设置里全局选择硬件解码或软件解码，并在播放页“更多”列表里对当前会话切换，以便个别格式硬解异常（绿屏/花屏）时立即自救。
10. 作为用户，我想打开应用先看到首页，只有本地、SMB、WebDAV 三个来源入口，以便快速决定从哪里开始。
11. 作为用户，我想首页左上角有汉堡按钮、标题居中出现，以便随时进入设置并确认当前应用。
12. 作为用户，我想首页三个入口只显示图标与名称，以便界面保持简洁。
13. 作为用户，我想点击某个协议入口后看到该协议的连接源列表，以便集中管理同类来源。
14. 作为用户，我想源列表只显示连接源名称，以便快速识别已有连接。
15. 作为用户，我想源列表右下角有加号按钮，以便随时新增连接。
16. 作为用户，我想在没有连接源时看到空状态提示，但加号仍可用，以便知道下一步该做什么。
17. 作为用户，我想新增 SMB 连接时填写名称、服务器地址、路径、用户名与密码，以便连接局域网共享。
18. 作为用户，我想 SMB 服务器地址不填端口时默认 445，以便少填一项。
19. 作为用户，我想 SMB 路径可以只填共享名，也可以填共享名加子目录，以便直接进入常用目录。
20. 作为用户，我想 SMB 路径留空时列出服务器上的共享，以便不知道共享名时也能浏览。
21. 作为用户，我想新增 WebDAV 连接时填写名称、服务器地址、起始目录、用户名与密码，以便连接网盘或 NAS。
22. 作为用户，我想 WebDAV 地址不写端口时，http 默认 80、https 默认 443，以便少填一项。
23. 作为用户，我想 WebDAV 起始目录可空，为空时从服务器地址根目录开始，以便按需缩小浏览范围。
24. 作为用户，我想连接源名称可空，留空时 SMB/WebDAV 使用服务器地址、本地使用文件夹名，以便不想命名时也能保存。
25. 作为用户，我想编辑已保存的 SMB/WebDAV 连接，以便修改地址、路径或凭据。
26. 作为用户，我想删除连接前二次确认，且只删除本地记录与凭据、不删远程文件，以便避免误操作。
27. 作为用户，我想本地来源通过系统文件夹选择器添加，并且可以添加多个文件夹，以便管理不同磁盘位置。
28. 作为用户，我想本地连接源只提供删除，不提供编辑，以便操作符合它没有凭据的事实。
29. 作为用户，我想保存连接后它立即出现在源列表，以便确认保存成功。
30. 作为用户，我想点击连接源进入库页面，以便浏览该来源的根目录。
31. 作为用户，我想库页面顶栏显示汉堡按钮、当前目录名、视图按钮与排序按钮，以便不离开浏览就能调整展示。

## Implementation Decisions

（每条对应 ADR，实现时以 ADR 为准）

- **技术栈**：Kotlin + Jetpack Compose；minSdk 26 / targetSdk 35（ADR-0001）。
- **播放核心**：libmpv，集成路线基于 mpv-android 官方构建产物；渲染用 libmpv 的 Surface 挂载（OpenGL→Surface）嵌入 Compose AndroidView；版本锁定（ADR-0006/0019）。
- **进程模型**：单一 PlaybackService（前台服务）持有 mpv 实例与 MediaSession，Activity 仅绑定；通知栏控制由 MediaSession 提供（ADR-0009/0019）。
- **播放逻辑接缝**：`PlaybackController` 播放会话接口承载循环三态状态机、自动连播开关、“下一集恒按名称排序”、定时暂停、进度记忆决策、耳机断开暂停、淡入触发（ADR-0007/0011/0015/0016）。
- **媒体接缝**：`MediaFile` 统一抽象 + `MediaLibrary`；本地走 SAF（多根目录持久授权，不申请存储权限）；SMB 用 SMBJ（SMB2/3，禁 SMB1）；WebDAV 用 OkHttp 实现（PROPFIND/GET/Range）（ADR-0002/0020）。
- **导航与顶栏**：首页、源列表、库页面顶栏左侧统一为汉堡按钮（打开设置）；源列表与库页面不提供返回箭头。库页面顶栏右侧为视图与排序按钮。设置页返回进入前的界面。系统返回逐级回退，首页首次返回提示“再按一次退出”，2 秒内再按才退出；返回栈可跨后台恢复（ADR-0022）。
- **连接源模型**：统一保存名称、服务器地址、路径或起始目录、用户名；密码单独加密保存。名称可空，回退规则见 ADR-0022。表单只显示字段标题，不显示“可空”或括号说明。
- **SMB 与 WebDAV 浏览根**：SMB 路径为空时枚举共享作为根；WebDAV 从起始目录开始，起始目录为空时从服务器地址根目录开始（ADR-0002/0022）。
- **WebDAV 访问**：允许 `http://` 明文地址并在应用层开启明文流量；PROPFIND 的目录地址统一以 `/` 结尾，避免依赖服务器目录重定向（ADR-0002）。
- **列表与排序**：视图为列表 / 网格 2/3/4 列；排序为名称升序、名称降序、修改时间 新→旧、修改时间 旧→新；子目录恒在文件之前；视图与排序都在库页面顶栏提供（ADR-0010）。切换排序与长按排序按钮回到顶部；切换视图仍按目录位置记录定位（ADR-0023）。
- **目录位置记忆**：按连接源与相对目录记录第一个可见条目与偏移，进入目录时恢复；与播放进度分开（ADR-0023）。
- **字幕**：mpv 内部 libass 渲染；外挂字幕经 `sub-add` 加载；内嵌/外挂互斥；匹配规则为同目录同前缀，srt/ass（ADR-0008）。
- **手势**：左右各 18% 竖条上下拖动调系统媒体音量，中间 64% 左右拖动跳转（整屏宽对应 5 分钟）；中间双击暂停/继续，左右侧双击 ±10 秒；单击显隐控制条并延迟到双击窗口结束；位移超过 9dp 才进入音量调整；顶栏与底部控制条不响应手势，面板打开时禁用手势；不提供亮度手势（ADR-0014）。
- **播放页控制层**：底部播放/暂停严格居中，上一集在左，下一集在右，字幕紧挨播放列表放在右下区域，播放列表在右下角，更多在右上角；未锁定时锁定按钮在左下角，与上一集/播放/下一集同一水平线；锁定时只保留左上角白色解锁按钮，左、上留白相同，3 秒自动隐藏、点画面重现、点一次解锁；“更多”面板无标题栏，所有选项以带勾选的列表呈现。
- **播放列表与上下集**：播放列表选择按媒体位置解析目标，不把显示下标直接当作播放索引；上一集、下一集与列表选择共用同一套索引解析。切集需区分自然播完与播放被替换触发的事件，避免误触发连播。
- **缓冲与切集**：冷启动黑屏中央显示缓冲指示；切集暂停原视频并保留冻结画面，缓冲指示叠在其上；两者都在 500ms 后才显示提示；失败取消切换并保持暂停，返回行为按场景区分；暂停态以抓帧成功作为首帧就绪；加载 60 秒无任何事件按失败处理；后台无可渲染画面时以文件加载完成作为就绪（ADR-0024）。
- **后台播放**：设置项“后台播放”默认开；开时退后台音频继续，关时退后台立即暂停且通知栏播放键不恢复；回前台重新挂载 Surface，挂载幂等（ADR-0009/0019）。
- **方向**：设置四选一，默认随系统；“跟随视频”监听宽高比变化旋转；竖屏视频视口居中（ADR-0013）。
- **音频**：起播与 seek 后 500ms 淡入；监听系统耳机断开广播立即暂停（ADR-0016）。
- **持久化**：Room 存进度记录（以媒体路径为唯一键：位置、时长、修改时间）；连接源书签与目录位置记忆用 DataStore；密码入 EncryptedSharedPreferences；设置用 DataStore，包含后台播放开关（ADR-0018）。
- **缩略图**：本地视频用 MediaMetadataRetriever 抽帧、音频提取内嵌封面；网络源按字节范围读取开头后同样抽帧；缓存键为“位置 + 修改时间”，修改时间缺失时保持占位图，LRU 清理；网络提取失败保持占位图；网络条目不提取时长（ADR-0017/0021）。
- **视觉规范**：首页入口与源列表条目共用卡片规格（外宽 328dp、圆角 20dp、图标 48dp、上下内边距 18dp、左右内边距 16dp）；设置行最小高度 52dp，开关 44×26，右侧控件同一基准线，弹出选项右对齐；全局不显示点击涟漪；浏览列表与网格不显示类型说明。
- **应用图标**：白底 + 蓝色播放三角；108 视口内三角缩小 20%，按视觉重心居中（ADR-0004）。
- **交付分期**：MVP 含首页连接源管理、网络源与外挂字幕；第 2 期含定时/淡入/耳机/后台/目录位置记忆；第 3 期打磨（ADR-0005）。

## Testing Decisions

- **只测外部行为**：通过接缝驱动、断言可观察结果，不测实现细节。
- **接缝 1（PlaybackController）**：注入 fake 播放引擎 + 假时钟，覆盖循环三态状态机、自动连播开关两种取值、“下一集”恒按名称排序、定时暂停到点暂停/重选替换、“播完本集”、100% 清进度 vs 中途保留、耳机断开即暂停、淡入在起播/seek 时被触发；切集时暂停原视频、500ms 缓冲提示阈值、就绪后切换、失败取消并保持暂停、缓冲期返回取消、重复切集不生效；播放列表与上下集按媒体位置解析，替换事件不触发自然连播。
- **接缝 2（MediaLibrary）**：注入 fake 文件树（含本地/模拟网络节点），覆盖目录即列表、名称/时间排序、外挂字幕匹配评分，以及 SMB 路径为空时的共享枚举根、WebDAV 起始目录根。自然排序为表驱动纯函数测试（`2`<`10`、大小写、混合数字段等 Windows 语义用例）。
- **接缝 3（连接源仓库与库状态）**：覆盖新增/编辑/删除连接源、名称回退、保存后连接源立即出现在列表、本地源不可编辑、删除只移除本地记录、删除连接源清理位置记录。
- **接缝 4（设置状态）**：覆盖解码/起播位置/目录位置开关/后台播放开关的取值与持久化读回，以及用户可见文案与选项顺序；视图与排序不再由设置页提供。
- **接缝 5（目录位置记忆）**：覆盖按连接源与目录分别记录、恢复第一个可见条目与偏移、关闭开关后从顶部开始、条目不存在时停在末尾、切换排序回到顶部、切换视图仍按记录定位、与播放进度互不影响。
- **接缝 6（导航状态）**：覆盖子目录到源列表到首页的逐级回退、设置页返回来处、首页二次返回窗口、后台恢复后层级不丢失。
- **接缝 7（WebDAV 地址与请求）**：覆盖 `http://` 与 `https://` 地址、端口默认值、起始目录、PROPFIND 目录地址末尾斜杠；用 fake transport 断言实际请求地址。
- **接缝 8（缩略图）**：覆盖网络条目进入抽取流程、缓存键包含修改时间、抽取失败保持占位图、成功后就绪替换。
- **先例**：现有 `SettingsViewModelTest`、`LibraryStateTest`、`NetworkSourceRepositoryTest`、`WebDavStreamsTest`、`CachedMediaPreviewSourceTest` 等按接缝注入 fake 的写法，新增测试沿用。
- **不做**：mpv/FFmpeg/SMBJ 等第三方库行为不测；Compose UI 仅关键路径冒烟（首页入口、源列表、库页面、设置项、播放控制条），不纳入验收标准。

## Out of Scope

- 在线字幕下载、弹幕、投屏（DLNA/Cast）、画中画、倍速播放、均衡器/音效、HLS/DASH 在线流媒体协议、视频转码、桌面/iOS 版本、SMB1、上架应用商店。
- 列表内拖拽手动排序（排序只按名称/时间）。
- 连接源导入/导出、跨设备同步、多选批量删除、连接源排序与分组。
- 亮度手势与窗口亮度调节（亮度始终跟随系统）。
- 服务端缩略图、预生成封面、整文件下载后再抽帧。
- 预加载多个待播条目；切集只缓冲目标条目。
- 手势分区宽度、拖动灵敏度、双击窗口的自定义设置。
