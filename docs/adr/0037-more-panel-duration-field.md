# ADR-0037 更多面板的自定义时长输入框形态

状态：已接受

## 背景

播放页「更多」面板的「自定义分钟数」输入框需要同时满足三件事：宽度收窄到与其他控件协调、行高与面板统一、提示文字居中。

实测当前使用的 Material3 1.3.2 没有 `TextFieldLabelPosition`，也没有带 `contentPadding` 的重载（这两项是 1.4+ 的能力）。带浮动标签的 `OutlinedTextField` 总高 = 可见边框 48 + 标签悬出 8 = 56；压到 48 总高后可见边框只剩 40，比相邻的 48dp 行明显矮一截。标签宽度由内容决定并固定行首对齐，`textAlign` 改不动它的落点。

## 决策

- **宽度 140dp**：扣掉左右各 16dp 内边距后余 108dp，「自定义分钟数」六字约 87dp，余量 21dp，字号放大到 1.2 倍仍不截断。
- **该行高度 56dp，可见边框 48dp**：总高比其它行多 8dp，多出的正是标签悬出区；可见边框与其它行的 48dp 对齐，观感一致。
- **只居中输入内容**，浮动标签保持行首对齐：受 Material3 1.3.2 限制，不做自绘。
- **空值提示沿用浮动标签**，不改成内联占位。

## 后果

- 定时区块最后一行比其余行高 8dp，行高不严格统一；换来看得见的边框高度一致。
- 标签不居中，与使用者最初「提示文字也居中」的要求有出入，属于当前依赖版本下的能力边界。
- 若将来升级 Material3 到 1.4+，可重新评估标签居中。

## 备选

- **自绘输入框（BasicTextField + 边框）**：能同时做到 48dp 与标签居中。否决，因为全应用输入框（含网络源表单）都是 M3 浮动标签式，这一处自绘会成为唯一例外，提示还需改成内联，样式与其它输入框不一致。
- **压到 48dp 总高**：可见边框只剩 40dp，比相邻行矮，视觉上凹进去。否决。
- **升级 Material3 到 1.4+**：可直接支持标签定位。否决，依赖升级影响面超出本票，且需要单独回归。
- **把该行并入其它行高约束**：会让可见边框高度与行高都不准确。否决。
