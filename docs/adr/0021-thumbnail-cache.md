# ADR-0021 缩略图缓存

状态：已接受

## 决策
- 视频抽帧：由 Media3 的 `FrameExtractor` 抽取；本地按比例取多个候选，网络取 `min(max(1% 时长, 1 秒), 30 秒)` 主候选并在不合格时退到 60 秒、90 秒，时长未知时取 1 秒。跳过纯黑、纯色与近黑帧（详见 ADR-0027）。结果缩放到 320–512px 宽（网络目标宽 320）后压 JPEG 80–85，存 files/thumbnails/ 磁盘缓存（Coil 管理加载），不缓存全尺寸帧。
- 音频封面：系统内嵌封面（ID3 APIC / flac PICTURE / m4a covr）优先，取不到或系统图解码失败时用自实现的 ID3v2 APIC 解析再取一次；同目录缓存，列表缩略图与播放页封面层共用这一份，封面层只读命中、不各自解码。
- 网络文件同样抽帧：SMB/WebDAV 随机读句柄包装成 Media3 的 DataSource，交给 Media3 FrameExtractor；不整文件下载。
- 缓存键为“媒体位置 + 大小 + 修改时间 + 抽帧策略版本 + 目标宽度”；修改时间缺失时退化为“媒体位置 + 大小 + 抽帧策略版本 + 目标宽度”，不设有效期，缓存一直有效。
- 缓存容量 128–256MB，LRU 清理。
- 网络缩略图按需提取，失败或超时不写入缓存，界面保持占位图。
- 本地同时抽取不超过 2 个，网络不超过 2 个；同一键的并发请求合并，缓存命中后的时长补读同样合并。
- 进入目录后可见项优先，前后各预取 1 行，离屏请求取消；应用启动并恢复目录后，不等列表卡片组合完成即为第一屏可见范围入队。
