# ADR-0021 缩略图缓存

状态：已接受

## 决策
- 视频抽帧：本地与网络都按比例抽取多帧，跳过纯黑/纯色帧，全部不合格时退到约 33% 处；结果缩放到 320–512px 宽后压 JPEG 80–85，存 files/thumbnails/ 磁盘缓存（Coil 管理加载），不缓存全尺寸帧。
- 音频封面：从 ID3 APIC / flac PICTURE / m4a covr 提取，同目录缓存。
- 网络文件同样抽帧：SMB/WebDAV 按字节范围读取，交给 MediaMetadataRetriever；不整文件下载。
- 缓存键为“媒体位置 + 大小 + 修改时间 + 抽帧策略版本 + 目标宽度”；修改时间缺失时退化为“大小 + 有效期”，有效期纳入键。
- 缓存容量 128–256MB，LRU 清理。
- 网络缩略图按需提取，失败或超时不写入缓存，界面保持占位图。
- 本地同时抽取不超过 2 个，网络不超过 3 个；同一键的并发请求合并，缓存命中后的时长补读同样合并。
- 进入目录后可见项优先，前后各预取 1–2 行，离屏请求取消。
