# ADR-0045 系统栏收放不改变浏览界面布局

状态：已接受

## 背景

进入播放页会隐藏系统栏，退出时恢复。浏览界面按实时的系统栏 inset 撑开顶部，系统栏一恢复，顶部留白变大，列表整列下移并重新测量，看起来像是被顶下去一截。

## 决策

- 浏览界面（首页、源列表、库页面、设置页）的顶部布局使用**只增不减**的系统栏 inset：一次运行内取已出现过的最大值，系统栏收放不回缩。
- 系统栏显隐只由播放页状态驱动：进入播放页隐藏，离开播放页恢复；其它界面不做沉浸切换。
- 播放页内部仍读实时 inset 摆放顶栏与底栏：那里画面占满全屏，需要跟随系统栏显隐让位。
- inset 由根布局的单一入口提供，各界面只消费，不各自计算。
- 列表滚动位置按条目 location 与像素 offset 记录，不依赖绝对屏幕坐标，因此 inset 变化不影响已记录的定位。

## 后果

- 退出播放页时列表零位移。
- 分屏、折叠屏展开等让 inset 永久变大的场景按最大一次留白，不回缩；Activity 重建后重新采样。
- 全屏返回浏览界面后，顶部会立刻按「系统栏存在」留白，即使那一帧系统栏还没画出来。

## 依据

只取最大值的稳定 inset 让「系统栏恢复」不触发布局变化；实测差异集中在退出播放页这一帧。
