# ADR-0027 缩略图生成与缓存

状态：已接受

## 决策

- 视频缩略图按比例抽取多帧：本地不超过 3 帧，网络不超过 2 帧。
- 跳过纯黑或纯色帧；全部不合格时退到约 33% 处。
- 时长未知时改用固定候选位置，最后一个作为兜底；候选仍按纯黑/纯色规则筛选。所有候选都不可用时保持占位图。
- 缓存命中时复用缓存中记录的时长，不重复读取；时长读取失败不影响已命中的图片。
- 抽取失败后按缓存键退避重试：首次 30 秒，随后倍增，上限 10 分钟；退避期间保持占位图，到期后的下一次请求重试。
- 无可用图片时仍可记录时长；时长读取失败不否定已抽取的图片，也不落盘为“确定无时长”。
- 抽帧策略版本变化使旧缓存失效；升级后允许首次冷抽。
- 抽帧结果先缩放到 320–512px 宽，再压 JPEG 80–85；不缓存全尺寸帧。
- 缓存键包含位置、大小、修改时间、抽帧策略版本与目标宽度；修改时间缺失时退化为大小加有效期。
- 本地同时提取不超过 2 个，网络不超过 3 个；帧与时长共用一次读取会话；同一键的并发请求合并。
- 缓存容量 128–256MB，LRU 清理。
- 进入目录后可见项优先，前后各预取 1–2 行；离屏请求取消。不使用系统级后台任务预生成。
- 提取失败保持占位图；网络条目不在界面显示时长，不把时长写入缩略图结果；为按比例选帧可在同一次抽取会话内读取时长。
- 不引入 ffmpeg 或额外解码依赖；继续使用系统媒体元数据接口。
