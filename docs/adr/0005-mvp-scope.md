# ADR-0005 交付节奏与 MVP 边界

状态：已接受（2026-10-05，第 1 轮 Q5，用户修订：网络源与外挂字幕必须进 MVP）

## 决策
- **第 1 期（MVP）**：本地媒体列表（排序、网格 2/3/4、Windows 名称排序）+ 播放器（拖动进度、锁定、上下集、暂停、播放列表、循环模式）+ mkv 内嵌字幕 + **外挂字幕（srt/ass 同目录自动加载）** + 进度记忆 + 硬/软解切换 + 沉浸式全屏 + **SMB/WebDAV 网络源**
- **第 2 期**：定时暂停、音频淡入（起播/跳转）、耳机拔出暂停、后台播放、自动滚到上次位置（带设置开关，默认开）
- **第 3 期**：打磨（方向自适应细节、性能、缓存策略）
