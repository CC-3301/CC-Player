# ADR-0014 播放器手势

状态：已接受

## 决策
- 手势分为三个区域：左侧 10% 竖条、右侧 10% 竖条、中间 80% 区域；双击分区按左右各 15% 划分。
- 顶栏区域与底部控制条区域不响应手势；任一播放面板打开时所有手势不响应；锁定后播放手势禁用，锁 UI 的唤醒与解锁操作除外。
- **音量**：左右两侧竖条内上下拖动，直接修改系统媒体音量；拖动位移超过 9dp 才生效，点击与双击不改变音量。
- **进度**：在中间区域左右拖动，整屏宽对应 5 分钟；拖动中显示目标时间与增减量，画面同步预览到目标位置，松手才落定。
- **滚轮**：鼠标滚轮上滚后退 5 秒、下滚前进 5 秒，连续滚动累积；与拖动进度共用同一套目标时间提示与画面预览，不进入音量或其它手势。
- **双击**：中间 70% 区域暂停/继续；左侧 15% 倒退 10 秒；右侧 15% 前进 10 秒。双击判定窗口 300ms。鼠标指针隐藏后的第一次左键及其双击窗口只唤醒，不执行双击动作。
- **单击**：显示或隐藏控制条；单击动作延迟到双击窗口结束，避免与双击冲突。鼠标指针隐藏后的第一次左键只唤醒，不执行单击动作。
- 不提供亮度手势；亮度始终跟随系统。
- 未锁定时，锁定按钮在底部控制条左下角，与上一集、播放、下一集同一条水平线，无背景圆圈。
- 锁定时只保留左上角解锁按钮：左、上留白相同，白色打开的锁图标，5 秒后自动隐藏；点画面重新显示，锁 UI 已显示时点击锁 UI 才解锁，不弹提示。鼠标指针隐藏后的第一次左键只显示锁 UI 与指针，不解锁。
- 锁定后播放手势禁用。
