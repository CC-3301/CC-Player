# ADR-0024 缓冲指示与切集过渡

状态：已接受

## 决策

- 冷启动或首次打开媒体时，播放画面保持纯黑，屏幕正中显示转圈，转圈下方显示“正在缓冲”；首帧可显示后撤掉。
- 缓冲提示延迟 1000ms 出现。1000ms 内首帧就绪时不显示提示，直接显示画面。
- 切集（上一集、下一集、播放列表选集）立即暂停原视频并保留当前画面；转圈与“正在缓冲”叠在冻结画面上；下一集首帧就绪后直接替换画面。不使用黑屏遮罩，唯一例外是抓帧不可得（无可显示的视频帧，如音频源）：此时用黑底等待。
- 切集同样使用 1000ms 阈值：1000ms 内就绪时不显示提示。
- 缓冲指示为透明叠层，转圈直接叠在冻结画面上，不铺黑底。
- “就绪”指首帧可显示，不是文件加载完成。暂停态以抓帧成功作为首帧就绪；抓帧探测不设独立短超时。
- 加载在 60 秒内没有任何事件时按失败处理；任一加载事件都会重置计时。
- 退到后台、没有可渲染画面时，首次打开与切集都以文件加载完成作为就绪；回前台由 Surface 重挂恢复画面。
- 目标加载期间只允许返回与上一集/下一集，其余操作全部禁用；恢复原片期间额外允许播放/暂停，其余仍禁用。
- 连点上一集/下一集时目标实时前移，最终直接从目标集开始加载，不经过中间集。
- 自动下一集与手动切集共用同一套切换与就绪判定。
- 切集失败时取消本次切换，恢复原视频并保持暂停，提示“播放失败”；原进度不变。用户在恢复期间按过播放，则恢复完成后继续播放；原位置在片尾时从头开始播放。
- 失败恢复时原位置在片尾（如自动下一集失败），原片保持片尾不动，以文件加载完成作为就绪，画面黑底暂停；不重复报失败。
- 从浏览页点入的首次缓冲期间只允许返回；切集缓冲期间按返回取消切换，留在原视频并保持暂停。
- 切集缓冲期间原视频保持暂停，不输出原视频音频；新视频首帧就绪后开始播放。
