# ADR-0024 缓冲指示与切集过渡

状态：已接受

## 决策

- 冷启动或首次打开媒体时，播放画面保持纯黑，屏幕正中显示转圈，转圈下方显示“正在缓冲”；首帧可显示后撤掉。
- 缓冲提示延迟 500ms 出现。500ms 内首帧就绪时不显示提示，直接显示画面。
- 切集（上一集、下一集、播放列表选集）立即暂停原视频并保留当前画面；转圈与“正在缓冲”叠在冻结画面上；下一集首帧就绪后直接替换画面。不使用黑屏遮罩。
- 切集同样使用 500ms 阈值：500ms 内就绪时不显示提示。
- “就绪”指首帧可显示，不是文件加载完成。暂停态以抓帧成功作为首帧就绪；抓帧探测不设独立短超时。
- 加载在 60 秒内没有任何事件时按失败处理；任一加载事件都会重置计时。
- 退到后台、没有可渲染画面时，切集以文件加载完成作为就绪；回前台由 Surface 重挂恢复画面。
- 切集缓冲期间重复切集不生效。
- 切集失败时取消本次切换，恢复原视频并保持暂停，提示“播放失败”；原进度不变。
- 冷启动缓冲期间按返回退出播放页；切集缓冲期间按返回取消切换，留在原视频并保持暂停。
- 切集缓冲期间原视频保持暂停，不输出原视频音频；新视频首帧就绪后开始播放。
