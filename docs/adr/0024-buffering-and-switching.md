# ADR-0024 缓冲指示与切集过渡

状态：已接受

## 决策

- 冷启动或首次打开媒体时，播放画面保持纯黑，屏幕正中显示转圈，转圈下方显示“正在缓冲”；首帧可显示后撤掉。
- 缓冲提示延迟 1000ms 出现。1000ms 内首帧就绪时不显示提示，直接显示画面。
- 从浏览页点入视频时，进入播放页立即显示缓冲指示，不受 1000ms 延迟约束；切集与其它首次打开仍按 1000ms 延迟。
- 切集（上一集、下一集、播放列表选集）立即暂停原视频并保留当前画面；冻结画面保持原始宽高比例并铺满视频可视区，不裁成正方形。转圈与“正在缓冲”叠在冻结画面上。新画面可显示的证据出现前一直保留冻结画面，不撤成黑底；用黑底的例外只有抓帧不可得（如音频源）与片尾。
- 切集同样使用 1000ms 阈值：1000ms 内就绪时不显示提示。
- 缓冲指示为透明叠层，转圈直接叠在冻结画面上，不铺黑底。文字使用 2dp、scrim 85% 的深色描边；转圈使用强调色，尺寸 36dp、粗细 3dp。
- “就绪”指新视频帧已可显示，不是文件加载完成。证据只接受两种：抓帧成功返回非空画面，或播放位置前进；首个位置事件只重建基线，超过 2000ms 的跳变不计为前进。等不到证据时，若已收到加载完成或画面信号，2 秒后按就绪收尾，但不撤冻结画面；60 秒无任何事件按失败处理。seek 指令成功不算证据。
- 抓帧在后台调度器执行，取消主线程有界等待，抓帧结果显式记为有帧或无帧。
- 切集抓帧设 2 秒上限。抓帧返回无结果时按无帧继续加载；抓帧未返回时不下发目标加载，按切集失败收尾：保留原画面并暂停，恢复原片字幕状态，原进度不变，日志来源记“抓帧超时”。原位置在片尾时保持黑底暂停。
- 手动切集（上一集、下一集、播放列表选集）完成后自动播放，即使切集前处于暂停；切集失败恢复原片时仍保持暂停。
- 加载在 60 秒内没有任何事件时按失败处理；任一加载事件都会重置计时。
- 退到后台、没有可渲染画面时，首次打开与切集都以文件加载完成作为就绪；回前台由 Surface 会话重挂恢复画面。暂停态回前台不以播放位置前进作为证据，由 seek 到当前位置后的抓帧成功确认画面恢复。
- 目标加载期间只允许返回与上一集/下一集，其余操作全部禁用；恢复原片期间额外允许播放/暂停，其余仍禁用。
- 连点上一集/下一集时目标实时前移，最终直接从目标集开始加载，不经过中间集。
- 自动下一集与手动切集共用同一套切换与就绪判定。
- 播完判定使用 mpv 的 `eof-reached` 属性，并开启 `keep-open=yes`：文件结束时停在末帧、不卸载，属性变为 true 即触发下一集；不依据 `END_FILE` 猜测结束原因，也不使用“已播放时长”门槛。
- 切集失败时取消本次切换，恢复原视频与画面并保持暂停，提示“播放失败”；原进度不变。用户在恢复期间按过播放，则恢复完成后继续播放；原位置在片尾时从头开始播放。
- 失败恢复时原位置在片尾（如自动下一集失败），原片保持片尾不动，以文件加载完成作为就绪，画面黑底暂停；不重复报失败。
- 从浏览页点入的首次缓冲期间只允许返回；切集缓冲期间按返回取消切换，留在原视频并保持暂停。
- 切集缓冲期间原视频保持暂停，不输出原视频音频；新视频首帧就绪后开始播放。
