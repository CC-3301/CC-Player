# ADR-0013 屏幕方向

状态：已接受（2026-10-05，第 3 轮 Q14，含用户追加）

## 决策
设置四选一：`屏幕方向（默认） / 横屏 / 竖屏 / 跟随视频`
- **屏幕方向（默认）**：跟随系统自动旋转设置（系统开关开→传感器，关→竖屏）
- **横屏 / 竖屏**：强制固定
- **跟随视频**：按视频宽高比判定（≥1 横屏，<1 竖屏），且**播放中持续监听宽高比变化并随之旋转**（多比例视频不中途抖动则由同一比例段决定）
- 竖屏播放时视频按宽高比视口居中
- 播放页标题栏：横竖屏都有，背景透明，内容为返回与文件名；叠加在画面上，不占布局高度；锁定态下不显示
- **跟随视频**模式下宽高比未知（起播瞬间、纯音频）时按「屏幕方向」处理
- **跟随视频**模式下按宽高比强制锁定，手动旋转不生效
