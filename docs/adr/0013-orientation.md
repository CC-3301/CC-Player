# ADR-0013 屏幕方向

状态：已接受

## 决策
设置四选一：`屏幕方向（默认） / 横屏 / 竖屏 / 跟随视频`
- **四个档位都由设备传感器判定，且不受系统“自动旋转”开关影响**：系统开关关闭时，播放页同样跟设备翻转。
- **只跟 180° 反向，不做 90° 跨族切换**：锁定档位下，物理把设备转 90° 不会从横屏跳到竖屏；只有同族内翻到另一侧（正向 ↔ 反向）才跟着翻，画面始终正向可读。
- **屏幕方向（默认）**：4 向全跟——竖、反向竖、横、反向横。
- **横屏**：固定在横屏族，族内判正向与反向。
- **竖屏**：固定在竖屏族，族内判正向与反向。
- **跟随视频**：先按视频宽高比定族（≥1 横屏，<1 竖屏），再在族内判正向与反向；**播放中持续监听宽高比变化并随之旋转**（多比例视频不中途抖动则由同一比例段决定）。
- 方向判定加迟滞，阈值按步进区分：换向要求新方向比当前方向接近超过 30°，相邻 90° 步进即进入 61°、退回 29°，族内 180° 对即进入 106°、退回 74°。手机平放或斜放时不得来回跳。
- **角度未知时按档位施加**：设备接近水平、架在支架上或传感器不可用时，横屏、竖屏与跟随视频取期望族——已施加方向属于该族则保持不变，否则取族正向；“屏幕方向”档交回系统，不锁成竖屏，首个有效角度到达后再四向接管。角度只决定族内正反向，不是施加方向的前提。
- **用户操作优先于传感器**：方向设置变化与转屏按钮立即施加，不经过去抖；传感器驱动的换向需连续 3 帧同一方向才施加，单帧跳变与中途回摆不换向，角度再次未知时保留已施加方向。
- 竖屏播放时视频按宽高比视口居中
- 播放页标题栏：横竖屏都有，背景透明；左侧依次为返回按钮与文件名，右侧为转屏按钮与更多按钮；叠加在画面上，不占布局高度；锁定态下只显示解锁按钮
- **跟随视频**模式下宽高比未知（起播瞬间、纯音频）时按「屏幕方向」处理
- 播放页转屏按钮始终生效，只覆盖本次播放，不修改设置中的档位
- 离开播放页时方向交回系统；此时若系统自动旋转关闭，界面会立刻回到系统方向
