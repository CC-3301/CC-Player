# ADR-0022 首页与连接源管理

状态：已接受

## 背景

应用同时支持本地文件夹、SMB 与 WebDAV 三种来源。来源入口、凭据管理与媒体浏览原先混在同一个媒体库页面，添加连接源后看不到新内容，用户也难以判断从哪里开始。

## 决策

- 应用启动进入首页。首页顶栏左侧是汉堡按钮（打开设置），中间标题为 CC Player。
- 首页只有三个协议入口：本地、SMB、WebDAV。每个入口显示图标与名称，不显示说明文字。
- 点击入口进入该协议的源列表。源列表顶栏左侧是汉堡按钮，不提供返回箭头；离开靠系统返回。
- 源列表只显示连接源名称；没有连接时显示空状态，加号仍可用。
- 源列表右下角圆形加号打开新增连接。
- 本地新增使用系统文件夹选择器（SAF），选中目录即成为连接源。本地连接源只提供删除，不提供编辑。
- SMB/WebDAV 新增打开表单；已有连接通过条目的更多菜单编辑或删除。删除需要二次确认，只删本地记录与凭据，不删远程文件。
- 连接源名称可空。为空时，本地源使用文件夹名，SMB/WebDAV 使用服务器地址。
- SMB 表单字段：名称、服务器地址、路径、用户名、密码。表单只显示字段标题，不显示“可空”或括号说明。服务器地址为主机，可带端口，端口默认 445；路径为共享名加子目录，可空；路径为空时列出服务器共享。
- WebDAV 表单字段：名称、服务器地址、起始目录、用户名、密码。地址必须以 `http://` 或 `https://` 开头，端口默认 http 80、https 443；起始目录可空，为空时从服务器地址根目录开始。
- 保存前校验服务器地址非空；WebDAV 还需校验 scheme。校验失败保留表单并显示错误。
- 保存成功后连接立即出现在源列表，不自动进入。
- 选择连接源进入库页面，根目录为该连接的本地根、SMB 路径根或 WebDAV 起始目录。
- 库页面顶栏从左到右为：汉堡按钮、当前目录名、视图按钮、排序按钮。不提供返回箭头；离开子目录靠系统返回。
- 首页入口与源列表条目使用同一套卡片规格：左右外边距 16dp、圆角 20dp、图标 48dp、上下内边距 18dp、左右内边距 16dp。
- 设置可从首页、源列表与库页面进入；设置页顶栏左侧保留返回按钮，返回时回到进入前的界面。
- 首页与源列表不展示连接源地址、路径或凭据。

## 后果

- 连接源的浏览入口与凭据管理分离，库页面不再包含来源菜单。
- 新增连接源按“选协议 → 点加号 → 填表单”三步完成。
- 删除连接源时，其目录位置记录一并删除。
