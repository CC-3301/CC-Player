# ADR-0008 字幕加载规则

状态：已接受

## 决策
- 内嵌字幕与外挂字幕同时存在时：**外挂一律自动加载进字幕轨道列表，默认显示内嵌字幕**；没有内嵌轨道时默认显示匹配到的外挂字幕（多候选取评分最高者）
- 播放器内字幕菜单列出：内嵌轨道 + 可匹配的外挂字幕文件 + 关闭
- 手动选择外挂字幕时：外挂生效，**内嵌字幕停止显示**（二者互斥，同一时刻只有一路生效）
- 外挂字幕匹配：同目录文件，与视频同名前缀匹配（如 `ep01.chs.ass` 匹配 `ep01.mkv`），格式限 srt/ass
- 渲染字体以内嵌中文字体子集兜底，片源指定的字体名不做逐条映射（ADR-0047）
