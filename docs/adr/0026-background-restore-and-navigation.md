# ADR-0026 后台恢复与导航状态

状态：已接受

## 决策

- 退到后台时若处于暂停，先缓存当前帧再分离 Surface；抓帧最多等待 2 秒，超时先分离，回前台由刷新与抓帧恢复。回前台先显示缓存帧，等 mpv 输出新帧后撤掉。播放中退后台不截帧，回前台由 mpv 继续输出。
- **暂停态回前台用「seek 到当前位置」逼播放核心重绘一帧**：重建视频输出不会自己出帧，抓帧也就拿不到，界面停在黑屏；seek 不改变播放位置，但必然触发重绘。播放态回前台先等 500ms 让画面自然输出，等不到再用同一个 seek 兜底。
- 暂停态回前台不依赖播放位置前进：seek 之后的出帧或抓帧成功才算画面恢复，避免暂停时永远等不到“位置前进”。
- 导航状态由单一导航协调器持有：当前屏、源协议、设置页来处、库页面目录栈一次快照、一次恢复。当前屏为库页面时目录栈必须非空；恢复失败且用户仍停留于恢复目标时回首页，用户已导航则放弃本次恢复并记录日志。
- 系统返回按界面优先级消费：播放页 → 设置页 → 首页 → 源列表 → 库页面。只有首页在二次确认后才结束 Activity，其它状态一律不退出。播放页返回先取消切集，没有切集才关闭播放页；取消切集不额外提示。
- 进程被回收后恢复当前屏、连接源、设置页来处、库目录栈与浏览位置。浏览位置恢复不受“目录位置记忆”开关影响；开关只影响正常进入目录。
- 冷启动恢复由“启动时回到上次浏览的目录”开关控制，默认开；只对库页面生效，恢复连接源、完整目录栈与该目录滚动位置；上次停在其它界面或源/目录失效时回首页。
- **冷启动恢复判定完成前不渲染任何界面**，只显示纯色底；不得先画出首页再跳转，也不得把目录栈逐级播放给用户看。
- 播放页状态不持久化：进程被回收后不回到播放页，也不恢复播放会话。
- 不引入导航框架；导航协调器基于现有导航状态与目录位置记录完成恢复。
