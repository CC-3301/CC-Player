# ADR-0026 后台恢复与导航状态

状态：已接受

## 决策

- **打开另一个目标**：与切集区分。打开从浏览界面进入另一个目标时撤掉旧画面、旧片立即停止出声，新目标出画面或加载完成才放声并重新淡入；方向与比例按新目标判定，不沿用上一个目标。切集（上一集、下一集、播放列表选集、片尾自动）维持旧画面留到目标首帧。
- **退到后台不分离 Surface**：暂停态屏幕停住的最后一帧原样保留，回前台保留该帧；播放态回前台不保留旧画面，撤掉屏上那一帧、纯黑等新帧，黑屏期间不显示转圈与文字。后台切集不继承屏上旧画面。Activity 的停止与恢复不拆不挂；Surface 销毁回调、关闭播放页与销毁时分离。
- **不抓帧、不缓存帧、不扩展出帧判定**：不恢复后台抓帧与缓存帧体系；除暂停态重挂的撤黑判据外，不把任何信号当作常规出帧证据。播放态回前台等播放位置前进；**暂停态 Surface 重挂后主动请求刷新一帧**：发一次位置中性的精确刷新（`seek 0 relative+exact`），由播放核心重解当前帧——这正是 mpv 自己在 vo/wid 变更时使用的刷新手段；不改变播放位置、不做跳转、不抓图。判据：暂停态回前台保留最后一帧，播放态回前台撤掉旧画面、纯黑等新帧，黑屏期间不显示转圈与文字；后台切集不继承屏上旧画面。被系统回收 Surface 时才重建，重建期间铺黑底等新帧。暂停态 Surface 重挂时，以刷新自己的 PLAYBACK_RESTART（帧上屏回执）作为撤黑判据，仅暂停态生效；每次进入恢复都允许一次刷新：暂停态发位置中性刷新（同一次恢复只发一次；片尾暂停、已到结尾、切集仍在等目标帧时不刷新），播放态只等播放位置前进。播放态仍只认播放位置前进，不把该判据扩展为常规出帧判定。片尾与切集等目标帧期间不刷新。音频不得出现可听出的中断、爆音或重音；音频焦点与退后台音频约束见 ADR-0009。
- 挂载或回前台播放态撤帧后 3 秒仍未收到新帧时只做一次视频输出翻转（VO 置空后恢复），不 seek、不改播放位置；暂停态先发位置中性刷新，刷新回执未到时同样进入这次翻转兜底；翻转后仍无帧则保留黑底并结束本次恢复（已知边界）。
- 导航状态由单一导航协调器持有：当前屏、源协议、设置页来处、库页面目录栈一次快照、一次恢复。当前屏为库页面时目录栈必须非空；恢复失败且用户仍停留于恢复目标时回首页，用户已导航则放弃本次恢复并记录日志。
- 系统返回按界面优先级消费：播放页 → 设置页 → 首页 → 源列表 → 库页面。只有首页在二次确认后才结束 Activity，其它状态一律不退出。播放页返回按播放状态分档（见「返回语义」一节）。
- 进程被回收后恢复连接源、设置页来处、库目录栈与浏览位置。当前屏为设置页时按设置页来处恢复，设置页本身不作为恢复目标——与冷启动同一套判定。浏览位置恢复不受“目录位置记忆”开关影响；开关只影响正常进入目录。
- 冷启动恢复由“启动时回到上次浏览的目录”开关控制，默认开；恢复连接源、完整目录栈与该目录滚动位置。上次停在库页面直接恢复；上次停在设置页时按设置页来处恢复——来处是库页面则恢复该目录，来处是源列表则回该源列表，来处是首页则回首页；设置页本身不作为恢复目标。设置只有这三个入口，播放页不能直接进设置。上次停在首页、源列表或源/目录失效时回首页；快照读不出或无法解析按失效处理并记录原因，首次启动没有快照不算失效。
- **冷启动恢复判定完成前不渲染任何界面**，只显示纯色底；不得先画出首页再跳转，也不得把目录栈逐级播放给用户看。
- 播放页状态不持久化：进程被回收后不回到播放页，也不恢复播放会话。
- 不引入导航框架；导航协调器基于现有导航状态与目录位置记录完成恢复。

## 返回语义

返回要拆成两件事：离开播放页，和是否结束播放；两者不再绑定。

- 系统返回、全面屏手势返回与鼠标侧键返回三者等价。
- 「播放中 / 暂停 / 片尾停留」：返回回到浏览界面（离开前停留的那一屏），App 仍在前台；是否继续播放由「APP 内后台播放」开关决定（ADR-0009），开则音频继续、关则停止播放。
- 「切集中」：返回只取消这一跳，留在原片，不离开播放页。
- 「首次加载 / 恢复原片 / 错误态」：返回退出播放页，回到浏览界面。
- 面板或抽屉打开时：返回先关面板。
- 左上角返回按钮总是结束播放并回到浏览界面；系统返回只在内后台播放关闭、首次加载、恢复原片与错误态时结束播放。

不采用「返回 = 把任务移到系统后台」：返回的落点是 App 内的浏览界面；继续播放时通过系统通知栏的媒体卡片回到播放页（ADR-0028）。
