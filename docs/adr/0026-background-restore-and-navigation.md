# ADR-0026 后台恢复与导航状态

状态：已接受

## 决策

- 退到后台时若处于暂停，先缓存当前帧再分离 Surface；回前台先显示缓存帧，等 mpv 输出新帧后撤掉。播放中退后台不截帧，回前台由 mpv 继续输出。
- 不采用强制 seek 或强制重绘来恢复画面。关闭后台播放不改变恢复行为。
- 系统返回严格逐级回退；播放页关闭后回到进入前的导航屏，不跳到首页。
- 进程被回收后恢复当前屏、连接源、设置页来处、库目录栈与浏览位置。浏览位置恢复不受“目录位置记忆”开关影响；开关只影响正常进入目录。
- 播放页状态不持久化：进程被回收后不自动回到播放页，也不恢复播放会话。
- 不引入导航框架；继续使用现有导航状态与目录位置记录完成恢复。
