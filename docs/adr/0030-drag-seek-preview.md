# ADR-0030 拖动进度的实时画面预览

状态：已接受

## 决策

- 拖动进度、滚轮调时长期间，画面实时预览到目标位置：按约 150–200ms 节流向播放核心下发真实 seek，界面显示的画面就是目标时间的那一帧。
- 松手收尾：目标与最后一次已下发的预览 seek 目标相同时不再重复下发 seek，只恢复声音并淡入——同一目标连跳两次会让画面先闪一下再落定；目标不同才补一次精确 seek。拖动被取消时同样落定到当前预览位置，不退回原位。
- 滚轮连续滚动共用一次收尾：停滚 1 秒后才收尾，窗口内再滚一格顺延，不重复落定。
- 预览期间进度条与时间标签跟随预览目标，不回落引擎位置；只有引擎位置真正到达目标附近后才恢复跟随引擎值，避免 seek 中途回跳。
- 预览 seek 期间静音，松手恢复声音并保留既有的 500ms 淡入。逐次 seek 各自触发淡入会造成拖动过程中断续爆音。
- 预览 seek 不得污染加载与切集的状态判定：预览期间不产生切换完成证据、不改缓冲提示、不触发自动连播、不写播完判定。只有松手或取消后的收尾 seek 才按正常 seek 记录。
- 首次加载、切集、恢复原片、时长未知时不做预览 seek，行为与现状一致。
- 采用真实 seek 而非时间轴缩略图：缩略图是低清抽样，做不到“当前播放界面上的画面就是目标帧”。代价是远程源逐帧预览会受网络寻址限制，表现为滑动跟随有延迟。
