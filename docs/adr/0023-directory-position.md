# ADR-0023 目录位置记忆

状态：已接受

## 决策

- 设置项名称为“进入目录时自动回到上次停留的位置”，默认开。
- 每个连接源、每个相对目录路径记录一份浏览位置。
- 位置记录包含该目录中第一个可见条目与滚动偏移。
- 进入目录时恢复该目录上次停留的位置，与上次播放的条目无关。
- 关闭该设置时，进入目录从顶部开始；已有记录保留，重新开启后继续使用。
- 记录中的条目已不存在时，停在列表末尾。
- 切换排序或视图不删除记录；排序变化后优先按记录条目定位，条目不存在时停在末尾。
- 位置记录跨应用重启保留，与播放进度记录分开，互不影响（ADR-0011）。
- 删除连接源时，删除该连接源的全部位置记录。

## 后果

- 浏览位置按目录累积，长期使用后需要随连接源删除或设置关闭来清理。
