# ADR-0023 目录位置记忆

状态：已接受

## 决策

- 设置项名称为“进入目录时自动回到上次停留的位置”，默认开。
- 每个连接源、每个相对目录路径记录一份浏览位置。
- 位置记录包含该目录中第一个可见条目、滚动偏移，以及写入该记录时的排序。
- 读取记录时与当前排序比对：一致才恢复位置；不一致视为没有记录，从顶部开始。这条判据取代「切排序后回顶」这类依赖时序的动作，因此排序切换与进目录谁先谁后，结果都一致。
- 进入目录时恢复该目录上次停留的位置，与上次播放的条目无关。
- 关闭该设置时，进入目录从顶部开始；已有记录保留，重新开启后继续使用。关闭期间位置记录继续更新，供进程回收恢复使用。
- 进程被系统回收后恢复时，即使该设置关闭，也恢复原浏览位置；设置开关只影响正常进入目录。
- 记录中的条目已不存在时，停在列表末尾。
- 切换排序后当前目录回到顶部；长按排序按钮也回到顶部（ADR-0010）。回到顶部后的浏览位置按正常滚动规则记录，并带上当时的排序。
- 切换视图不删除记录，仍按记录中的条目定位。
- 位置记录跨应用重启保留，与播放进度记录分开，互不影响（ADR-0011）。
- 删除连接源时，删除该连接源的全部位置记录。

## 后果

- 浏览位置按目录累积，长期使用后需要随连接源删除或设置关闭来清理。
