# ADR-0010 排序规则

状态：已接受

## 决策
- 名称排序 = **Windows 资源管理器自然排序**（等价 StrCmpLogicalW）：数字段按数值比较（`2` < `10`），字母不区分大小写
- 数字段数值相同时（`ep2` / `ep02`）前导零少的在前；整串只差大小写时按原始码点序排出确定次序
- 排序选项四种：名称升序、名称降序、修改时间 新→旧、修改时间 旧→新；默认名称升序
- 子目录恒排在文件之前，排序选项只作用于组内次序
- 修改时间相同时按名称自然排序
- 视图：列表 / 网格 2/3/4 列；视图与排序为两个独立选项，只在设置页提供
- 切换排序后按目录位置记录重新定位；记录条目不存在时停在末尾（ADR-0023）
- "下一集"的基准顺序恒为名称自然排序（见 ADR-0007）
