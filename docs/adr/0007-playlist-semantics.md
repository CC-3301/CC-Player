# ADR-0007 播放列表与"下一集"语义

状态：已接受（2026-10-05，第 2 轮 Q7/Q8）

## 决策
- **当前目录即播放列表**：播放某文件时，列表 = 该目录下所有媒体文件；同时支持手动播放列表（跨目录追加）作补充
- **"上一集/下一集/自动连播"的顺序基准 = 名称自然排序（Windows 规则，ADR-0010）**
  - 与列表视图当前排序方式无关：即使视图按修改时间排序，点击"下一集"播放的是名称排序下的下一个文件
- 循环状态机（文件播完时按当前模式决定）：
  1. **顺序播放**（默认）：自动播下一个，列表末尾停止
  2. **列表循环**：自动下一个，末尾回第一个
  3. **单集循环**：重播当前文件
- 设置项"自动播放下一个"（默认开）：
  - 开：顺序播放/列表循环模式下播完自动继续
  - 关：顺序播放/列表循环播完即停止（单集循环不受影响）
