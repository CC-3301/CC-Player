# ADR-0009 后台播放

状态：已接受

## 决策
- **APP 外后台播放**：设置项“APP 外后台播放”，默认开，管离开 App（按 Home、切换到最近任务或别的 App）后的行为。开：视频退到后台画面停止渲染，**音频继续**（前台服务 + MediaSession，通知栏含播放/暂停/上下集控制）。回前台自动恢复画面并继续播放，不重新缓冲；暂停态保留最后一帧，由播放核心重建视频输出后发一次位置中性刷新，以刷新自己的 PLAYBACK_RESTART（帧上屏回执）作为撤黑判据，仅暂停态重挂生效；播放态不保留屏上旧画面：一律撤掉那一帧、纯黑等新帧，黑屏期间不显示转圈与文字，不 seek、只等播放位置前进；后台切集不继承屏上旧画面。回前台撤帧后同样进入等新帧恢复，3 秒无新帧只翻转一次视频输出，翻转后仍无帧保持黑底并结束本次恢复。外层不抓帧探测、不用其它间接信号判定画面已上屏。关：退到后台立即暂停；通知栏只保留暂停，播放、上一集、下一集都不生效；回前台显示暂停帧并保持暂停，由用户手动继续。
- **音频焦点**：播放开始申请音频焦点。短暂丢失（加载中、暂停中同样算）暂停并记下恢复意图，拿到焦点后继续；永久丢失在任一状态都立刻停住，不记自动恢复，重新要出声时先申请焦点、拿不到就继续停住；暂降时把音频输出音量压到 20%，放弃焦点或会话结束时恢复到基准音量。暂停不释放焦点；后台播放开着时退后台与 Surface 拆挂不做任何音频命令（不暂停、不换 ao、不碰音频重配），Surface 分离保持异步投递。音频重配与 AO（`ao` / `current-ao`）变化写常驻观测日志，跟随诊断日志开关。
- **APP 内后台播放**：设置项“APP 内后台播放”，默认关，管在 App 内离开播放页（回到浏览界面）后的行为。开：音频继续，控制走系统通知栏媒体卡片；关：离开播放页即停止播放，通知栏卡片消失。
- 两者互相独立，不做交叉限制：例如外关内开表示「在 App 内逛目录时继续播，离开 App 就暂停」。
- 离开播放页后的片尾自动切集按设置里的「自动下一集」执行，不另设规则。
- 音频文件一律通过前台服务播放。
