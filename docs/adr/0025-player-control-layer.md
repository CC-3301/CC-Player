# ADR-0025 播放页控制层与视觉

状态：已接受

## 决策

- 顶栏与底栏透明，只在屏幕上下边缘保留极淡的内渐变，不使用实色底或整条遮罩。
- 标题在左上角紧挨返回按钮，单行省略；右上角依次为转屏按钮与更多按钮。
- 转屏按钮使用 Material `screen_rotation` 图标，点击直接在当前横竖屏之间切换；只影响本次播放，不修改设置中的屏幕方向；设置选“跟随视频”时同样生效。
- 进度条使用圆形滑块；左侧显示当前时间，右侧显示总时长。时间距屏幕左右各 16dp，时间与轨道间距 16dp，时间标签宽度贴合文字并分别左/右对齐；触控高度 36dp，视觉轨道 2dp。
- 播放页按钮图标整体放大：上一集/下一集按钮约 46dp，播放/暂停约 58dp，三键间距加宽。
- 播放列表图标：三条横线，仅第一条完整；第二、三条缩短，圆角三角嵌在右下并保留小空隙。
- 字幕图标使用官方 Material 字幕图形：实底圆角矩形，内部为字幕线样式；按钮常显，不随是否有字幕轨隐藏。
- 播放列表以低透明度渐变黑底从右侧滑出，占右半屏；打开时隐藏其它控制层，当前播放项自动居中，点左半屏关闭。
- 播放列表文字全部白色；编号为至少两位数字，距抽屉左边缘 16dp，编号到标题 16dp；标题单行省略；当前项保留淡蓝底与蓝色 ▶；顶部计数标题文字为白色，文案与位置不变。
- 更多与播放列表打开后均可点击其它区域关闭。
- 控制层 5 秒无操作自动隐藏；任意操作重置计时；面板打开时不隐藏；锁定态沿用同一规则。显示与隐藏使用 200ms 淡入淡出，不使用位移。
- 切集与加载期间，除上一集/下一集外，其余可见控件保持原亮度与外观，只拦截点击，不降低透明度。
- 拖动进度时屏幕正中显示大号目标时间，下方显示同字号白色增减量，不使用底板。
- 双击左侧显示 ◀◀、右侧显示 ▶▶，下方显示 3 秒内累计秒数；黑色半透明涟漪从该侧屏幕边缘向内扩散。
- 视频未覆盖区域使用纯黑，不使用主题色。
- 退出播放页时先恢复系统栏，再切换页面，避免浏览页因 insets 变化跳动。
