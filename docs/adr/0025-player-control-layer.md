# ADR-0025 播放页控制层与视觉

状态：已接受

## 决策

- 顶栏与底栏透明，只在屏幕上下边缘保留极淡的内渐变，不使用实色底或整条遮罩。
- 标题在左上角紧挨返回按钮，单行省略；右上角依次为转屏按钮与更多按钮。
- 转屏按钮使用 Material `screen_rotation` 图标，点击直接在当前横竖屏之间切换；只影响本次播放，不修改设置中的屏幕方向；设置选“跟随视频”时同样生效。
- 进度条使用圆形滑块；左侧显示当前时间，右侧显示总时长。时间距屏幕左右各 16dp，时间与轨道间距 16dp，时间标签宽度贴合文字并分别左/右对齐；触控高度 36dp，视觉轨道 2dp。拖动期间左右时间标签固定为两侧较大宽度，拖动结束恢复贴合文字。
- 上一集、播放/暂停、下一集三个热区等宽等高：总宽 186dp，各 62dp，高 58dp，彼此无间隙；图标保持侧键 28dp、播放键 34dp。
- 播放页可见控件按下反馈为白色 20% 涟漪：图标按钮、更多面板行、自动连播行、文字按钮、播放列表行、字幕菜单行。整屏手势层、锁屏解锁层、面板外关闭层与进度条拖拽层不显示涟漪；未按下时不显示任何背景。
- 播放列表图标：三条横线，仅第一条完整；第二、三条缩短，圆角三角嵌在右下并保留小空隙。
- 字幕图标使用官方 Material 字幕图形：实底圆角矩形，内部为字幕线样式；按钮常显，不随是否有字幕轨隐藏。
- 播放列表以低透明度渐变黑底从右侧滑出，占右半屏；打开时隐藏其它控制层，当前播放项自动居中，点左半屏关闭。抽屉只在真正接触屏幕的边缘应用系统 inset，左侧不叠加；编号距抽屉左边缘 16dp 不受系统左 inset 影响。
- 播放列表非当前项文字与顶部计数标题为白色；编号为至少两位数字，距抽屉左边缘 16dp，编号到标题 16dp；标题单行省略；当前项编号为白色，淡蓝底从抽屉左边缘开始、右侧保留 4dp，右侧保留强调色 ▶；三角为 17.25sp、宽 24dp。
- 更多与播放列表打开后均可点击其它区域关闭。
- 控制层 5 秒无操作自动隐藏；任意操作重置计时；面板打开时不隐藏；锁定态沿用同一规则。显示与隐藏使用 200ms 淡入淡出，不使用位移。控制层隐藏时，已打开的更多、字幕与播放列表面板一并关闭并清理状态，不得保留不可见但仍拦截手势的面板。
- 切集与恢复期间，除上一集/下一集外，其余可见控件保持原亮度与外观，只拦截点击；首次打开仍按不可用外观置灰（返回入口除外）。
- 拖动进度时屏幕正中显示大号目标时间，下方显示同字号白色增减量，不使用底板。
- 双击左侧显示 ◀◀、右侧显示 ▶▶，下方显示 3 秒内累计秒数；黑色半透明涟漪从该侧屏幕边缘向内扩散。
- 视频未覆盖区域使用纯黑，不使用主题色。
- 退出播放页时先恢复系统栏，再切换页面，避免浏览页因 insets 变化跳动。
