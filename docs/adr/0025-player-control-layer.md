# ADR-0025 播放页控制层与视觉

状态：已接受

## 决策

- 顶栏与底栏透明，只在屏幕上下边缘保留极淡的内渐变，不使用实色底或整条遮罩。
- 标题在左上角紧挨返回按钮，单行省略；右上角依次为转屏按钮与更多按钮。
- 转屏按钮使用 Material `screen_rotation` 图标，点击直接在当前横竖屏之间切换；只影响本次播放，不修改设置中的屏幕方向；设置选“跟随视频”时同样生效。
- 进度条使用圆形滑块；左侧显示当前时间，右侧显示总时长。时间距屏幕左右各 16dp，时间与轨道间距 16dp，时间标签宽度贴合文字并分别左/右对齐；触控高度 36dp，视觉轨道 2dp。拖动期间左右时间标签固定为两侧较大宽度，拖动结束恢复贴合文字。
- 上一集、播放/暂停、下一集三个热区等宽等高：高 58dp，彼此无间隙；图标保持侧键 28dp、播放键 34dp。可用宽度足够时总宽 186dp、各 62dp；**可用宽度不足 378dp（竖屏常见）时各收窄到 52dp、总宽 156dp**。**播放键始终居中**：两侧通道各为（可用宽度 − 三键总宽）/2，右侧并排的字幕与播放列表需要 96dp，通道不足时六个按钮的热区与图标按同一系数等比缩小（`min(1, 通道宽度 / 96dp)`）直到放得下，**不改为上下排列**，六个按钮始终落在同一水平线上，播放键中心不偏移。缩放下限不设硬阈值，越窄越小。
- 播放页可见控件按下反馈为白色 20% 涟漪：图标按钮、更多面板行、自动连播行、文字按钮、播放列表行、字幕菜单行。整屏手势层、锁屏解锁层、面板外关闭层与进度条拖拽层不显示涟漪；未按下时不显示任何背景。
- 播放列表图标：三条横线，仅第一条完整；第二、三条缩短，圆角三角嵌在右下并保留小空隙。
- 字幕图标使用官方 Material 字幕图形：实底圆角矩形，内部为字幕线样式；按钮常显，不随是否有字幕轨隐藏。
- 播放列表抽屉：**横屏占右半屏，竖屏占下半屏**；打开时隐藏其它控制层，当前播放项自动居中。关闭区为抽屉之外的那一半：横屏点左半屏关闭，竖屏点上半屏关闭。
- 抽屉底色为**统一 50% 黑**，不做渐变；抽屉只在真正接触屏幕的边缘应用系统 inset，不接触的那一侧不叠加。
- 播放列表非当前项文字与顶部计数标题为白色；编号为至少两位数字，距抽屉左边缘 16dp，编号到标题 16dp；标题单行省略。**当前项序号与标题同样是白色，不随底色变化**；当前项底色为深蓝 30%，从抽屉左边缘开始、右侧保留 4dp；不使用右侧三角标记。
- 更多与播放列表打开后均可点击其它区域关闭。
- 按下控件即重置自动隐藏计时，按住期间不隐藏；淡出动画期间控件仍可点击；取消时间窗去抖，播放/暂停等动作按引擎真实状态幂等执行，重复投递不改变结果。
- 控制层 5 秒无操作完全隐藏：第 4 秒开始淡出、第 5 秒淡完（淡出 1 秒）；显示使用 200ms 淡入，不使用位移。任意操作重置计时（手势只重置计时，不显示控制层）；面板打开时不隐藏；锁定态沿用同一规则。控制层隐藏时，已打开的更多、字幕与播放列表面板一并关闭并清理状态，不得保留不可见但仍拦截手势的面板。
- 控制层隐藏时手势不唤出控制层，也不显示除下列以外的任何手势提示：拖动与滚轮调时长不显示目标时间与增减量，音量拖动不显示音量百分比，双击暂停/继续不显示任何界面元素，双击 ±10 秒只显示该侧箭头与累计秒数、不显示边缘涟漪。手势只重置自动隐藏计时；只有点击画面或控件才显示控制层。
- 控制层隐藏时切集（手动与片尾自动都算）全程不显示控制层，切完也不自动显示；缓冲指示与错误提示照常显示，它们不属于控制层。
- 控制层显示时，切集与恢复期间上一集/下一集与播放/暂停可点，其余可见控件按不可用外观置灰并拦截点击；播放/暂停的意图排队到切集就绪后按该意图收尾，上一集/下一集每击都前移目标、不排队。首次打开只放行返回，其余置灰。首帧加载状态只在本次播放还没开始过切集时让控制层显示，切过一次之后不再生效。
- 拖动进度时屏幕正中显示目标时间与增减量：**目标时间 44sp、增减量 36sp、两行间距 6dp**；增减量用方括号括起；均为白色、无底板、位置居中。
- 双击左侧显示 ◀◀、右侧显示 ▶▶，下方显示 3 秒内累计秒数；黑色半透明涟漪从该侧屏幕边缘向内扩散。
- 视频未覆盖区域使用纯黑，不使用主题色。
- 指针跟随控制层且瞬时显隐、不参与淡出：控制层隐藏时指针立刻隐藏；控制层可见时指针直接跟随鼠标，不做位移判定。隐藏期间鼠标移动要构成同向净位移才算真的在动：位移按向量累加成净位移，反向的位移自然抵消、换向（含垂直）的位移继续累加，净位移被抵消到不再推进时清零重开；相邻两次移动相隔超过 150ms 视为中断，累计同样清零、从这次事件重新起算。净位移长度达到 10dp 且这段累计持续满 150ms 才算真的在动。不构成有效移动的抖动既不唤出指针，也不重置隐藏计时。有效移动只让指针出现、控制层保持隐藏，点击画面或控件才唤出控制层；静止 3 秒隐藏；离开播放页时恢复；其它界面不处理指针。
- 退出播放页时先恢复系统栏，再切换页面，避免浏览页因 insets 变化跳动。
