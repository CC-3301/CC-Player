# ADR-0028 诊断日志与媒体通知

状态：已接受

## 决策

- 设置提供诊断日志开关，默认关闭。
- 开启后写单一日志文件，只保留最近两次会话：每次启动写一条会话标记；第三次启动时截掉最早那次会话。文件上限 8 MiB，超出先丢最旧会话，只剩本次会话仍超限时从本次最早的日志行开始丢弃，保留最近的；不写半行。
- 记录应用生命周期、播放状态迁移、加载与切集结果、播放核心错误文本与目标文件标识、导航跳转、未捕获异常堆栈；不记录密码。
- 记录加载看护重试与判失败、Surface 重挂与恢复结果、缩略图抽取失败三类事件。
- 导出文件同时写入应用版本、设备型号与系统版本。
- 后台连接线程必须在边界捕获 `RuntimeException`/`Throwable`，网络读超时按连接失败收尾，不得终止进程。
- 导出为纯文本文件，通过系统分享面板发送。
- Java 崩溃由全局未捕获异常处理器写入日志；原生崩溃无法由 Java 捕获，只保留 mpv 日志。
- 不提供“上次异常退出”提示，用户自行决定是否导出。
- 媒体通知的标题为去掉扩展名的文件名；总时长写入媒体元数据。
- 通知封面取自缩略图缓存，取不到时使用应用图标；通过文件提供器向系统暴露图片。
- 回退用的应用图标必须是单层非自适应位图：自适应图标直接按画布绘制会叠加出多个三角。
- 记录屏幕方向切换事件；缩略图抽取失败除异常类型外还要记录异常消息，否则无法定位失败原因。
- 播放中约每秒刷新一次通知位置，并声明系统拖动定位动作。
- 后台播放关闭且应用在后台时，通知动作仍只保留暂停。
