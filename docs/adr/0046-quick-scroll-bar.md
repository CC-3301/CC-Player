# ADR-0046 库页面右侧快速滚动条

状态：已接受

## 背景

一个目录可能有几百个条目，只能靠滑动找目标，越往后越难定位。列表已有按条目记录的滚动位置，但缺少「直接跳到大致位置」的手段。

## 决策

- 只有库页面的列表与网格视图提供右侧快速滚动条覆盖层；首页、源列表、设置页不提供。
- 形态：宽 6dp、最短 64dp 的圆角条，贴屏幕右缘，长度与位置按可见范围在总条目中的比例表达；不显示当前位置气泡、不显示文字、不显示条目名。
- 显隐：滚动、按下或拖动时出现；静止 1200ms 后淡出；淡入 120ms，淡出 200ms。
- 触摸热区：屏幕右缘向内 32dp 的竖带。滚动条完全隐藏时不占用该带，触摸照常落到列表。
- 拖动映射：按下位置按 thumb 长度换算成滚动行程比例，再按行换算成列表项；网格按行计算，落在目标行的第一项。定位使用滚动到目标项，不直接改写滚动偏移。
- 只有落在热区内的按下才由滚动条接管，其余触摸仍归列表滑动与点击。
- 拖动结束不恢复原位置，停在落点；列表自身的滚动位置照常按条目记录。

## 后果

- 条目多的目录可以直接拖到目标附近再微调，不再依赖长距离滑动。
- 网格视图的定位精度是行，一档跨多格。
- 快速拖动会连续改变可见范围，封面调度按新可见范围重排，旧范围的抽帧请求丢弃（见封面流水线）。

## 依据

同一交互在条目数上到数百时收益明显；无气泡是刻意的取舍，避免遮挡右侧条目。
