# ADR-0017 列表网格卡片内容

状态：已接受

## 决策
- 卡片 = 缩略图 + 文件名；列表行与网格卡片都不显示“文件夹 / 视频 / 音频”说明，也不显示时长角标。
- 视频：由 Media3 的 `FrameExtractor` 抽帧；本地按比例取多个候选并跳过纯黑、纯色与近黑帧，全部不合格时退到约 33% 处；网络取 `min(max(1% 时长, 1 秒), 30 秒)` 主候选，时长未知时取 1 秒，主候选不合格时退到 60 秒，最多 2 个候选。抽帧与缓存细节见 ADR-0027。
- **音频：优先显示文件内嵌封面**（mp3 ID3 APIC / flac PICTURE / m4a covr 等），无内嵌封面时用音符占位图；网络音频同样提取。系统取内嵌封面失败、取不到或系统图解码失败时，用自实现的 ID3v2 APIC 解析再取一次，只解封面帧、不做完整标签解析、不引入第三方标签库；标签可读但没有封面帧才算无图，读取失败或系统图解码失败按抽取失败记录阶段。
- 缩略图/封面统一走磁盘缓存目录，LRU 清理。
- 网络缩略图先显示占位图，提取完成后替换；提取失败保持占位图。
- 网络条目不在界面显示时长；为挑选候选会读一次时长，但不写入缩略图结果。
