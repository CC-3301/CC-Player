# ADR-0017 列表网格卡片内容

状态：已接受

## 决策
- 卡片 = 缩略图 + 文件名 + 时长角标；列表行与网格卡片都不显示“文件夹 / 视频 / 音频”说明。
- 视频：本地按比例抽取多帧并跳过纯黑/纯色帧，全部不合格时退到约 33% 处；网络取 max(1% 时长, 1 秒) 处单帧，时长未知时取 1 秒。抽帧与缓存细节见 ADR-0027。
- **音频：优先显示文件内嵌封面**（mp3 ID3 APIC / flac PICTURE / m4a covr 等），无内嵌封面时用音符占位图；网络音频同样提取。
- 缩略图/封面统一走磁盘缓存目录，LRU 清理。
- 网络缩略图先显示占位图，提取完成后替换；提取失败保持占位图。
- 网络条目不在界面显示时长，也不单独读取时长。
